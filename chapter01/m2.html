模块二：表位与抗原特异性

为什么疫苗“专病专防”？为什么同一个病原能让机体产生“认得出但不一样”的多种抗体？答案都在这里——抗原的“分子指纹”：表位（抗原决定簇）。这是本章的教学难点，也是后续章节（抗体、体液免疫应答）反复使用的一页，务必结合图示吃透。

🎯 学习目标卡

  • 能说出表位的定义及其化学本质（氨基酸/多糖/核苷酸残基数范围）
  • 能用图解释线性表位与构象表位的本质区别，并预测“变性处理”后的影响
  • 能解释为什么 T 细胞受体只认“加工后的线性表位”，而 B 细胞可直接识别构象表位
  • 能用“一个抗原多种表位”解释多克隆抗体与交叉反应现象

📖 2.1 表位：特异性的结构基础

表位（Epitope / 抗原决定簇 Antigenic Determinant）

抗原分子中决定抗原特异性的特殊化学基团，是决定抗原特异性的结构基础。一般由 5–17 个氨基酸残基、5–7 个多糖或核苷酸残基组成（课件）。

三个关键推论（请边读边在抗原分子上想象“靶点”）：

  • 一个抗原分子往往含有多种、多个表位 → 免疫后产生的抗体是“针对多个表位”的多克隆抗体；
  • 表位决定了抗体/效应细胞“认”哪个部位 → 特异性；
  • 表位是反应原性的结构落点：上一模块的“小分子半抗原”，本质上≈单个表位大小的分子。
把两个模块接起来

免疫原性（能不能激发）的分子基础=整体分子+载体+递呈；反应原性（认不认得）的分子基础=表位。一个分子可以有强免疫原性但让人“只认其中一小块”——特异性由此而来。

🖼️ 2.2 两类表位：线性 vs 构象（可视化）

图 2-1 线性表位（E1）是肽链上连续排列的短肽；构象表位（E2）由空间折叠后靠拢的氨基酸共同形成。关键区分实验：把蛋白变性（破坏空间构象）——线性表位仍能被识别，构象表位则丢失。
比较项线性表位构象表位
空间结构氨基酸在肽链上连续排列氨基酸序列不连续，靠空间折叠聚拢
是否依赖构象否（变性后仍可识别）是（变性/去折叠后丢失）
常见识别者T 细胞（加工后）；也可被 B 细胞识别主要被 B 细胞（BCR/抗体）识别
对疫苗设计的意义重组短肽/线性肽疫苗需保持天然折叠——VLP、天然蛋白更优
启发式提问（课堂可用）

把某种病毒灭活（甲醛/加热处理）做成疫苗时，最担心丢失的是哪类表位？这对“灭活工艺不能过度”有何提示？——参考：构象表位。过度灭活破坏表面蛋白折叠 → 中和抗体关键表位丢失 → 疫苗效力下降。这也是“抗原质量决定疫苗质量”的又一体现。

🧠 2.3 难点突破：为什么 TCR 只认线性表位，而 BCR 能直接认构象表位？

T 细胞（TCR 识别）

  • TCR 只能识别线性表位；
  • 抗原必须先经 APC 摄取、降解加工成短肽，与 MHC 分子结合后“呈递”到细胞表面；
  • TCR 识别的是“MHC + 肽”复合物 → 天然构象蛋白 T 细胞“看不见”；
  • 意义：T 细胞负责核查内部加工后的情报（如病毒感染的细胞）。

B 细胞（BCR 识别）

  • BCR（膜型抗体）可直接识别天然蛋白表面的构象表位与线性表位；
  • 不需要 APC 预加工——看见“原样敌军”即结合；
  • 分泌型抗体识别的主要是表面构象表位（尤其是病毒中和表位）；
  • 意义：B 细胞负责拦截细胞外的敌军本体。
图 2-2 识别分工：BCR 直接结合天然蛋白表面（构象表位为主）；TCR 识别经 APC 加工、由 MHC 分子展示的线性肽段。这条“分工”将贯穿第二~八章的细胞免疫与体液免疫内容。
口头推理题（检验是否真懂）

某病毒疫苗用“完整灭活病毒”制成（保留天然构象）；另一款是“线性短肽疫苗”。哪一款更可能诱导针对病毒表面的中和抗体？为什么？哪一款更容易诱导 T 细胞应答？

参考思路（先自己推理再看）

完整灭活病毒保留了表面构象表位 → 更能诱导 B 细胞产生抗“构象表位”的中和抗体；线性短肽疫苗以线性表位为主，免疫后肽段可被加工递呈 → 更偏向诱导 T 细胞应答。两类疫苗各有侧重，这也是选择疫苗形式时要权衡的抗原学逻辑。

🧬 2.4 一个抗原，多种表位：多克隆抗体与交叉反应

现象①多克隆抗体一个抗原多个表位 → 免疫血清是“混编部队”
→
现象②交叉反应不同抗原含相同/相似表位（异嗜性抗原）→ 一抗认两“敌”
→
应用单抗与血清学单抗=针对单一表位（第十章）；交叉反应可用于病原亲缘分析
交叉反应小结

交叉反应的本质：抗体/效应细胞“认的是表位而不是整个病原”。例如不同血清型病原之间存在共同抗原成分时，血清学检测会出现交叉——这对诊断试剂的“特异性”设计既是干扰、也是可被利用的工具（如用共同抗原做属水平筛查）。

🧠 2.5 小结与自检

本模块知识地图

表位（决定特异性的化学基团）→ 线性 vs 构象（变性区分实验）→ T 认线性（加工+MHC）、B 认构象（直接） → 多种表位 → 多克隆抗体 / 交叉反应。请回答主线问题：疫苗为何专病专防？——因为特异性写在表位里，不同病原的表位不同。

选 B。变性破坏空间构象：构象表位丢失（抗体不再识别），线性表位仍保留（另一抗体仍识别）——这就是区分两类表位的经典实验逻辑。

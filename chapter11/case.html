案例教学：把疫苗知识“用起来”

三个案例分别对应“传统疫苗的国际贡献—新型疫苗的研发攻坚—多联疫苗的产业落地”三个兽医场景。学习方式：先读背景，暂停播放，自己写答案，再展开解析。案例解析按“背景 → 问题 → 知识分析 → 教师总结 → 专业启示”展开。

课件案例/成果理论→分析→判断→应用建议小组讨论

🐖 案例一：一株疫苗种毒的国际旅行——猪瘟 C 株背后的中国贡献

传统弱毒疫苗 · 国际合作思政：自主创制与大国担当

① 案例背景

猪瘟是由猪瘟病毒引起的急性、热性、高度接触性传染病，曾是危害世界养猪业最严重的疫病之一。中国科学家成功研制出猪瘟兔化弱毒疫苗（C 株）——把野毒株在兔体内反复传代“驯化”，得到毒力减弱但免疫原性保留的疫苗株。课件特别提到：中国曾将 C 株疫苗种毒赠送给匈牙利，助力其开展猪瘟防控。

② 生产 / 公共卫生问题

  • C 株是“弱毒活疫苗”——为什么这种“活着的疫苗”反而安全？
  • 为什么一株疫苗能跨越国界，成为多国猪瘟防控的“公共产品”？它靠什么赢得信任？
  • 既然 C 株这么好，为什么我们今天还在研究“如何区分疫苗株与野毒株”？

③ 知识分析（弱毒疫苗视角）

处置/现象其中的免疫学逻辑对应本章知识
C 株=兔化传代致弱强毒株在异源宿主（兔）中连续传代，毒力下降但保留免疫原性弱毒活疫苗“人工致弱”来源（模块二）
接种后仍能低水平增殖模拟“轻症感染”，抗原持续刺激弱毒疫苗体液+细胞免疫兼得（模块二）
安全、稳定、免疫原性好致弱充分 → 不致病；复制能力保留 → 免疫持久弱毒疫苗研制核心“大规模、高效、稳定”（模块二）
“分不清疫苗毒和野毒”血清学难以区分 → 影响检疫与净化判断活疫苗缺点 ①：鉴别难题（模块四/三难点）
④ 教师总结

猪瘟 C 株是“弱毒活疫苗”路线的教科书级胜利：用异源宿主传代致弱换来了安全，用体内增殖换来了高效。但它的成功也把“身份难题”摆上台面——防控越精细，越要分清“打的苗”和“感染的毒”。这正是疫苗学不断向前（基因缺失标记苗等）的内在动力。

⑤ 专业启示 · 课程思政

一株疫苗种毒能成为国际合作的“使者”，靠的是严谨的研制、过硬的质量与无私的分享。今天中国兽用疫苗已从“跟跑”走向“并跑”，更需要青年兽医在基础免疫学与生物技术上“挑大梁”——把疫苗做进猪舍里，也把中国方案带到世界疫病防控的现场。

🗂 本案例考查的知识点清单
  • 弱毒活疫苗的研制与致弱途径（M2）
  • 弱毒疫苗体液+细胞免疫优势（M2）
  • 活疫苗“疫苗株 vs 野毒株”鉴别难题（M3/M4）
  • 疫苗“预防”本质与免疫记忆（M1）

🧬 案例二：安全了却“不够能打”——非洲猪瘟基因缺失候选疫苗的研发之辨

新型疫苗 · 实验室成果思政：科研诚信与攻坚精神

① 案例背景

非洲猪瘟（ASF）是危害养猪业的“头号杀手”，全球尚无安全有效的商品化疫苗。我国科研团队探索基因缺失减毒活疫苗路线（课件“实验室成果”）：通过同源重组技术删除 ASFV 毒力相关基因（如 CD2v、MGF），获得基因缺失重组病毒，在原代巨噬细胞中扩增，并经 PCR 与测序验证后进行猪免疫与攻毒试验。

② 科研 / 生产问题

  • 为什么非洲猪瘟疫苗这么难做？（提示：病毒大、免疫逃逸复杂）
  • 双基因缺失毒株 ASFV-HNΔCD2vΔMGF“很安全”，为什么还不是合格疫苗？
  • “安全减毒”与“充分保护”之间，疫苗研发缺了什么？

③ 知识分析

研究环节（课件）免疫学角色对应本章知识
删除 CD2v、MGF 毒力基因去除毒力 → 减毒活疫苗候选株基因缺失疫苗原理（M3）
原代巨噬细胞扩增 + PCR/测序验证保证疫苗株纯度与遗传特征培养扩增/纯化检测环节（M2/M3）
免疫后攻毒试验评价是否诱导保护性免疫（中和抗体+细胞免疫）疫苗免疫效果评价（M1 免疫机理）
仅延迟发病、保护效率有限安全 ≠ 有效：未诱导充分保护“安全—有效”平衡（M3 讨论）
④ 教师总结

这个案例是“失败推动认知”的范本：基因缺失把病毒“剪”安全了，却可能同时削弱了激发保护性免疫所必需的抗原结构。非洲猪瘟病毒基因组庞大、免疫逃逸机制复杂，“单一删除几个基因就能得到好疫苗”的乐观预期被攻毒数据打破——疫苗研发必须回到安全、有效、稳定三要素的严格评价，任何一步都不能“拍脑袋”。

⑤ 专业启示 · 课程思政

课件如实呈现“保护效率有限”的结果，本身就是科研诚信的示范：好的研究不只报喜。非洲猪瘟疫苗是全球兽医界的“珠峰”，我国持续攻关、依法依规推进，正是把科技自立自强写进猪舍里的担当。青年兽医要有坐冷板凳、啃硬骨头的准备。

🗂 本案例考查的知识点清单
  • 基因缺失疫苗原理与流程（M3）
  • 攻毒试验与疫苗保护效果评价（M1/M3）
  • “安全 ≠ 有效”与候选株筛选（M3）
  • 减毒活疫苗的优缺点权衡（M4）

🧪 案例三：“一针防两病”——JEV-PPV 二联灭活疫苗的产业落地

校企合作 · 创新应用（课件）思政：把论文写在祖国大地上

① 案例背景

某规模化猪场（教学情境）种猪群反复出现流产、死胎等繁殖障碍，检测发现JEV（猪乙型脑炎病毒）与 PPV（猪细小病毒）混合感染；而 JEV 尚无猪源疫苗株，两者各自只有单苗。面对“混合感染 + 无联合疫苗”的痛点，教学团队与温氏集团联合研发 JEV-PPV 二联灭活疫苗（课件“创新应用举例”）。

② 生产问题

  • 为什么“混合感染”让单苗显得不够用？
  • 二联灭活疫苗怎么“造”出来？灭活→纯化→佐剂各解决什么问题？
  • 为什么要“首免 + 二免”？这背后的免疫学逻辑是什么？

③ 知识分析

研制步骤（课件）解决什么问题对应本章知识
JEV GZ 株、PPV GD 株扩增培养获得足量抗原原料灭活疫苗“大量培养”环节（M2）
灭活处理安全性：使病原不能感染灭活疫苗“甲醛等灭活”（M2）
超滤纯化去除杂质，保证质量与纯度纯化与检测环节（M2/M3）
ISA 201 VG 佐剂增强免疫原性、维持释放佐剂增强应答（M2 灭活苗加佐剂）
首免→二免基础免疫 + 加强免疫形成稳固记忆加强免疫逻辑（M4）
④ 教师总结

JEV-PPV 二联疫苗把“两条研制流水线”合为一条，本质是多联疫苗“减负增效”：一次接种同时覆盖两种导致繁殖障碍的病原，简化免疫程序、减少动物应激。它的每一步（选株—扩增—灭活—纯化—佐剂—首免二免）都是模块二“灭活疫苗研制”知识的生产级复现——课本上的流程图，就是产线上的真流程。

⑤ 专业启示 · 课程思政

从“猪场繁殖障碍”这个真问题出发，到与龙头企业联合研发、以免疫原性研究支撑产品落地——这正是产学研结合、把论文写在祖国大地上的兽医版本。疫苗研制永远从动物和产业的需要出发，这是应用免疫学的初心。

🗂 本案例考查的知识点清单
  • 灭活疫苗研制全流程（M2）
  • 佐剂作用与纯化意义（M2/M3）
  • 二联/多联疫苗与免疫程序（M4）
  • 疫苗“预防为主”与免疫评价（M1）
案例教学小结（对照“理论→分析→判断→应用”）

三个案例的共同“公式”：识别疫病威胁（是什么病原/什么场景）→ 判断免疫学对策（弱毒/灭活/基因缺失/多联）→ 权衡安全与有效 → 落地为研制流程与免疫程序。回到本章主线：疫苗不是神药，而是科学设计的“战前推演”；设计得越好，演习越接近实战，保护越可靠。你可以在课后作业“提升层”里再独立走一遍这个公式。

免疫预防 Immunoprophylaxis —— 新兵军事演习与战前推演

疫苗与免疫程序是动物疫病防控的核心武器：本章学习疫苗种类、免疫机理与科学免疫程序的制定。

Values Education · 课程思政

课程思政

本章的思政不做“贴标签”，而是从疫苗知识里长出来：每个融入点都按“专业知识 → 思政切入点 → 教学活动 → 价值引领”展开。学完每个点，请自问：这个知识点让我对“兽医在干什么、疫苗意味着什么”有了什么新认识？

4 个融入点配合案例教学效果更佳另有学科前沿见下页

★ 一、思政点 1：“人病兽防、关口前移”——兽医是公共卫生的第一道防线

  • 专业知识：疫苗防控的意义（模块一）；“坚持人病兽防、关口前移，从源头前端阻断人兽共患病的传播路径”——2021 年总书记关于生物安全建设的重要讲话（课件引述）。
  • 思政切入点：很多人的疫苗记忆是“给自己打针”，但狂犬病、布病等人兽共患病的第一道防线其实在动物——给动物免疫，就是在给人免疫。
  • 教学活动：案例一（猪瘟 C 株）延伸讨论“如果犬猫/家畜的免疫覆盖率不足，人兽共患病风险会怎样？”+ 课后思考“人病兽防”在我所学疫病中的实例。
  • 价值引领：树立大卫生观、大健康观，认同兽医职业在生物安全国家战略中的价值，增强职业使命感。

★ 二、思政点 2：从猪瘟 C 株到新冠疫苗——自主创制与科技自信

  • 专业知识：猪瘟兔化弱毒疫苗（C 株）研制与应用（模块二）；我国科研人员研发的重组新冠疫苗（5 型腺病毒载体）（模块三）。
  • 思政切入点：中国曾将 C 株种毒赠送匈牙利（课件），中国疫苗从“输入”走向“输出”；新冠疫苗多条技术路线并跑，是科技自立自强的缩影。
  • 教学活动：课堂 3 分钟“我为中国疫苗点赞”——每人讲一个“中国疫苗成就”；结合课件表格比较五类新冠疫苗技术路线。
  • 价值引领：激发民族自豪感与自主创新意识，认识到掌握核心疫苗技术对动物疫病防控和国家生物安全的意义。

★ 三、思政点 3：从“死苗要死透”到“缺失株防恢复”——生物安全与科研规范

  • 专业知识：灭活疫苗必须彻底灭活（甲醛灭活，模块二）；基因缺失疫苗病毒可能与野毒株重组或核酸修补恢复毒力（模块四活疫苗缺点②）；ASFV 候选株经 PCR/测序验证（模块三）。
  • 思政切入点：疫苗是“给健康动物用的”——安全红线不容侥幸。灭活不彻底、缺失株监测不到位，都会把“保护”变成“风险”。
  • 教学活动：课堂“找茬”——给出一张简化疫苗生产流程，让学生指出质量控制节点（纯化、无外源污染检测、理化性质、储存），讨论“为什么科研与产业都要讲规范”。
  • 价值引领：养成严谨求实、敬畏安全的科研与职业作风，理解 GMP/生物安全操作背后的生命关怀。

★ 四、思政点 4：从猪场问题到二联疫苗——把论文写在祖国大地上

  • 专业知识：JEV-PPV 二联灭活疫苗研制——针对种猪生殖障碍混合感染，与温氏集团联合研发（模块四、案例三）。
  • 思政切入点：研究起点不是“发论文”，而是猪场繁殖障碍这个真问题；成果落在“一针防两病”的产业应用上。
  • 教学活动：案例三讨论“如果我是研发者，我会怎么推进疫苗免疫原性研究？”+ 课后思考“兽医科研如何服务乡村振兴与养殖业现代化”。
  • 价值引领：树立产学研结合、服务产业的科研价值观，理解“把论文写在祖国大地上”在兽医学科的具体含义。
思政 × 前沿的“合流”问题（课堂讨论）

当基因工程让“造苗”越来越快、越来越“定制化”时——疫苗研发还需要什么？提示：还需要对真实疫病现场的准确判断（哪个毒株在流行？）、对安全与伦理的坚守（减毒株会不会恢复毒力？基因操作边界在哪？）、以及把“安全—有效—可用”落到每一批产品上的责任体系。技术越强，责任越大——相关前沿线索请移步 学科前沿 页。

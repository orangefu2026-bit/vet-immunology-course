Chapter 11 · Immunoprophylaxis · 章节首页

免疫预防：新兵演习，战前推演

本讲是整个国防类比的收尾章——前面十章回答了“敌军长什么样、国防军如何应战”，这一章回答“怎样让士兵在真正开战前先打一场演习”：疫苗是什么、按什么分类、灭活/弱毒/基因工程疫苗各自如何研制、怎么选、如何用。你将看懂一支疫苗从“选毒株”到“接种进动物体内”的全流程。

知识目标 3 项过程方法 2 项价值目标 3 项
贯穿本章的主线问题（建议带着它学习）

为什么给猪打一针疫苗，之后即使遇到猪瘟病毒，往往也只是“小感冒”甚至安然无恙？——疫苗不是“药”，它没有杀病毒的本领。它做的是一件更聪明的事：让免疫系统在和平时期先完成一场“演习”，记住敌军的样子。学完本章，请用“人工主动免疫 + 体液/细胞免疫应答 + 免疫记忆”把这句话说完整。

🎯 本章学习目标（三维 · 可评价）

建议学习结束后自检：能否不看资料，逐条说出每条目标的“做到标准”。

📘知识与技能

  • 能说出疫苗的定义（课件原文）并说明其“预防”而非“治疗”的本质；
  • 能按制备工艺/作用机制/所含成分说出疫苗种类，并举例（灭活、弱毒、亚单位、VLP、载体、核酸疫苗）；
  • 能复述灭活疫苗、弱毒活疫苗、基因缺失疫苗、基因工程活载体疫苗的研制流程；
  • 能归纳活疫苗优缺点，并解释“如何区分疫苗株与野毒株”是活疫苗研制的一大难题。

✅ 达标线：模块自测正确率 ≥ 80%

🧭过程与方法

  • 经历“生产问题 → 疫苗选择 → 研制路线 → 免疫效果评价”的分析链（案例教学）；
  • 学会用研制流程框图（选株—培养—灭活/致弱—纯化—制备）表达疫苗生产逻辑；
  • 能基于优缺点比较，为具体疫病提出“选哪类疫苗”的初步建议。

✅ 达标线：案例分析报告 ≥ 16/20 分

❤️情感态度与价值观

  • 理解“人病兽防、关口前移”，认同兽医在动物疫病与人兽共患病防控中的第一道防线作用；
  • 认识中国疫苗创制成就（猪瘟 C 株走向国际、我国科研人员研发腺病毒载体新冠疫苗）；
  • 树立生物安全与科研规范意识（灭活彻底性、基因缺失株的潜在风险）。

✅ 达标线：思政思考题 1 篇反思记录

🧱 本章重点与难点

学习时把精力集中投向这里。

教学重点

  • 疫苗的定义与人工主动免疫的本质（预防为主）；
  • 疫苗种类与“全病毒—蛋白—基因”三大抗原基础；
  • 四类疫苗（灭活、弱毒、基因缺失、活载体）的研制流程主线；
  • 活疫苗优缺点（体液+细胞免疫 / 无法区分疫苗株与野毒株等）。

教学难点（本网站为你配了“难点突破”设计）

  • 弱毒疫苗“既能诱导更强免疫，又说不清打的是疫苗株还是野毒株”——矛盾怎么破（引出基因缺失标记疫苗）；
  • 灭活疫苗与弱毒活疫苗优缺点相反，如何按疫病与生产场景选苗；
  • 基因缺失/活载体疫苗“怎么造”——理解基因操作在疫苗研制中的角色。

学情衔接

前置基础：第八章“适应性免疫应答”中已学过体液免疫（B 细胞 → 抗体）与细胞免疫（T 细胞），以及免疫记忆；第十章学过的免疫学技术为疫苗免疫效果评价（抗体检测、攻毒试验）提供工具。疫苗的本质，就是人为制造一次“安全的初次应答”，换来真正的免疫记忆。

后续衔接：本讲内容将用于临床各科（传染病学、产科学）、动物防疫法规与“免疫程序制定”等；猪瘟 C 株、非洲猪瘟疫苗攻关等话题也会在疫病防控课程与科研训练中反复出现。

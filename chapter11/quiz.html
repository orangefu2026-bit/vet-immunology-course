单选1 / 14 · 概念
下列关于疫苗概念表述最准确的是：
选 B（课件定义原文）。疫苗=生物制品，用于“人工主动免疫预防”，核心是预防而非治疗；原料可为病原微生物/寄生虫、代谢产物或基因工程产品。
对应：模块一 1.2 → 去复习
单选2 / 14 · 机理
疫苗免疫后保护作用的直接机制是：
选 A（课件原文）。疫苗靠“有效抗原成分”激活体液+细胞免疫应答并建立记忆；除弱毒/活疫苗等可在体内增殖外，多数疫苗本身不复制也不直接杀菌。
对应：模块一 1.3 → 去复习
多选3 / 14 · 种类
下列疫苗中，以“全病毒”为抗原基础、通过灭活或致弱获得的传统疫苗是：
选 A、C。灭活疫苗与减毒（弱毒）活疫苗都源自“全病毒”；亚单位疫苗取病毒蛋白、核酸疫苗给病毒基因，属于新型疫苗路线。
对应：模块一 1.4 → 去复习
单选4 / 14 · 种类举例
以下新冠疫苗与类型对应正确的是：
选 C（课件表格）。Comirnaty/Spikevax 为 mRNA 核酸疫苗，Nuvaxovid/智飞 ZF2001 为蛋白亚单位疫苗，CoronaVac/BBIBP-CorV 为灭活疫苗，Vaxzevria/Convidecia 为病毒载体疫苗。
对应：模块一 1.4 疫苗种类表 → 去复习
单选5 / 14 · 灭活疫苗
灭活疫苗研制中“1% 左右甲醛灭活”的直接目的是：
选 B。灭活=彻底杀死病原、消除感染性，保留能激活免疫的抗原表位（保留免疫原性），再配合佐剂制苗（课件流程图）。
对应：模块二 2.1 → 去复习
判断6 / 14 · 灭活疫苗特点
灭活疫苗研制周期短、安全性高，但免疫原性较差、成本较高、多需注射接种并常需佐剂与多次免疫。
正确（课件）。灭活苗安全、研制周期短；但病原已死、不能增殖，免疫原性弱、需佐剂与多次免疫，成本相对高、注射不便。
对应：模块二 2.1 优缺点表 → 去复习
单选7 / 14 · 弱毒疫苗
弱毒活疫苗的毒株来源包括：
选 D（课件）。弱毒株两个来源：自然界筛选天然弱毒株、强毒株人工致弱（如异源宿主传代）；弱毒株获得后大规模、高效、稳定培养是弱毒疫苗生产的核心。
对应：模块二 2.2 → 去复习
判断8 / 14 · 弱毒疫苗特点
弱毒活疫苗因病原已被灭活，接种后不能在体内增殖，因此必须加佐剂并多次免疫才能起效。
错误。“已灭活、不能增殖”是灭活疫苗的特征；弱毒活疫苗恰恰能在体内低水平增殖，持续刺激免疫系统，诱导更强的体液+细胞免疫，用量少、成本低。
对应：模块二 2.2 → 去复习
单选9 / 14 · 猪瘟C株
课件提到的“中国赠送给匈牙利”的猪瘟弱毒疫苗种毒是：
选 A（课件）。猪瘟弱毒疫苗（C 株）是中国研制的优秀弱毒疫苗，曾作为种毒赠送匈牙利，是弱毒疫苗应用范例。
对应：模块二 2.3 → 去复习
单选10 / 14 · 基因缺失疫苗
基因缺失疫苗研制最核心的步骤是：
选 C（课件）。核心=明确毒力基因→基因缺失去除→获得基因缺失（减毒）毒株，之后培养、扩增、纯化、检测并制备疫苗。
对应：模块三 3.1 → 去复习
判断11 / 14 · ASFV研究
课件中 ASFV 双基因缺失毒株 ASFV-HNΔCD2vΔMGF 虽具有良好的安全性和减毒特性，但免疫后仅延迟发病，对同源和异源毒株攻毒均未提供充分保护。
正确（课件原文）。该候选株安全减毒但保护效率有限——说明疫苗研发中“安全”不等于“有效”，必须通过严格攻毒试验评价保护效果。
对应：模块三 3.2 → 去复习
单选12 / 14 · 活载体疫苗
重组新型冠状病毒疫苗（5 型腺病毒载体）的构建思路是：
选 B（课件）。属于基因工程活载体疫苗：载体（ΔA，复制缺陷型腺病毒）+ 目的基因（S 蛋白基因）；单剂接种后 14 天可形成保护。
对应：模块三 3.3 → 去复习
多选13 / 14 · 活疫苗缺点
下列属于课件总结的“活疫苗缺点”的有：
选 A、B、D（课件缺点 3 条）。C 是活疫苗的优点（诱导体液+细胞免疫），不是缺点。
对应：模块四 4.1 → 去复习
情境 · 不计分14 / 14 · 迁移应用
某规模化猪场（教学情境）拟对后备母猪群进行免疫预防，需要预防的疫病包括：猪瘟（有经典弱毒疫苗 C 株可用）、以及 JEV 与 PPV 引起的繁殖障碍（现有 JEV-PPV 二联灭活疫苗）。请你用本章知识，从“疫苗种类选择（弱毒 vs 灭活）”“为什么 JEV-PPV 要做成二联灭活并‘首免+二免’”“如何评价免疫效果”三个角度，写一段 150–250 字的分析（提示：结合优缺点权衡、免疫记忆与佐剂）。
参考思路（开放题，言之成理即可）：① 猪瘟选 C 株弱毒活疫苗——能在体内低水平增殖，诱导较强体液+细胞免疫，用量少成本低，适合群体基础免疫；但需注意疫苗株与野毒株的鉴别（配合基因缺失标记/检测思路）。② JEV/PPV 引起种猪繁殖障碍且混合感染常见、单苗不便 → 做成二联灭活疫苗，既覆盖两种病原又安全（种猪/后备母猪尤其要防散毒风险）；灭活苗免疫原性弱，故需 ISA 201 VG 等佐剂并“首免+二免”，利用免疫记忆提高并延长抗体水平。③ 免疫效果评价：采血测抗体（中和/ELISA），必要时攻毒保护试验验证；评价终点是“降低发病/繁殖障碍、提高群体保护率”，同时监测野毒感染。
综合：模块二（灭活/弱毒）、模块三（鉴别）、模块四（选型与加强免疫）＋ 案例教学三个案例

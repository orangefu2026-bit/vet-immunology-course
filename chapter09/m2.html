Module 2 · 发生机制

模块二：Ⅰ型超敏反应的发生机制

这是本章的“发动机”：一节课若能讲清为什么“第一次没事、第二次爆发”，就抓住了 Ⅰ 型的精髓。本模块把课件机制原文拆成两阶段 + 一组介质，并给出“早发相/晚发相”难点突破。

学习目标难点突破在 2.4机制文字依据课件

🎯 学习目标卡

  • 能默画“变应原初次进入 → IgE → FcεRI → 致敏状态 → 再接触 → 脱颗粒”机制链
  • 能区分致敏阶段与激发/效应阶段，指出两个阶段各自做了什么
  • 能区分颗粒内“预先形成”介质（组胺/激肽原酶/嗜酸粒细胞趋化因子）与“新合成”介质（白三烯/PGD2）并说出主要作用
  • 能解释早发相与晚发相的时间差与细胞学基础（难点）

🗺️ 2.1 机制总览：一次“误击”的三步走

先把课件机制原文浓缩成一张流程图，再分节拆解。

课件机制原文（逐句保留）

变应原初次进入机体诱导 B 细胞产生 IgE，IgE 通过其 Fc 段与效应细胞表面 FcεRI 结合，使机体处于致敏状态；当变应原再次进入机体时，与已经结合在致敏靶细胞上的 IgE 特异性结合，引发细胞脱颗粒反应，释放生物活性物质引起机体病理改变。

阶段一 · 致敏第一次接触（无症）变应原 → B 细胞（依赖 IL-4）产 IgE → 结合肥大细胞 FcεRI → 待命
→
阶段二 · 激发第二次接触（扣扳机）变应原与致敏靶细胞表面 IgE 特异性结合（桥联）
→
阶段三 · 效应脱颗粒爆发（病理）释放组胺等介质 → 血管扩张/通透↑、平滑肌收缩、腺体分泌↑

🪧 2.2 致敏阶段：第一次接触，系统“装好了引信”

  • 入口：变应原经呼吸道、消化道、皮肤或注射等途径初次进入机体；
  • 抗体生成：变应原诱导鼻咽部、扁桃体、气管和胃肠道黏膜下固有层淋巴组织中的 B 细胞产生 IgE（产生依赖 IL-4，模块一已讲）；
  • 安装引信：IgE 通过其 Fc 段与肥大细胞/嗜碱性粒细胞表面高亲和性 FcεRI 结合——机体从此处于致敏状态；
  • 关键认识：致敏状态本身不引起症状，它只是“已上膛、未击发”。这也是“第一次接触没事”的机制原因。
细想一下

为什么致敏阶段“没症状”也危险？——因为致敏状态可长期维持（IgE—FcεRI 结合稳定），机体就像带着一枚“装了引信但不知何时引爆”的装置；下一次“何时、以何种途径”再遇到同一变应原，完全无法预判。

💥 2.3 激发与效应阶段：第二次接触，“引信点燃”

激发：桥联（cross-linking）

变应原再次进入，与已结合在致敏靶细胞表面的 IgE 特异性结合。由于一个变应原分子常可与相邻两个 IgE 的 Fab 同时结合，使相邻受体相互“桥联（交联）”——这是触发信号的关键一步。

效应：脱颗粒

受体桥联向细胞内传递激活信号，导致胞质嗜碱性颗粒与细胞膜融合、内容物外排，即脱颗粒反应；同时启动新介质合成。释放的生物活性物质作用于血管、平滑肌与腺体，引起病理改变。

图 2-1 激发—效应示意：变应原把相邻两个 IgE 桥联 → 受体交联激活 → 脱颗粒释放活性介质 → 全身/局部病理改变（致敏阶段见图 1-1）。
课堂快问（口头回答）

如果一个人体内 IgE 很多，但从未接触过花粉——他会不会在春天花粉季“突然发病”？为什么？

参考思路（先自己答再看）

不会（至少在首次接触前不会）。要发病必须满足“已致敏 + 变应原再接触”：没有第一次接触就没有针对该花粉的 IgE，也没有“装好的引信”。临床上“小时候不过敏、后来过敏”正是因为机体在更晚的时候才完成了第一次致敏。

🧯 2.4 生物活性介质：哪些“弹药”在开火（难点突破）

难点：介质多、易混。破解口诀——先分“新/旧”（预先形成 vs 新合成），再记“谁让血管通透、谁让支气管收缩”。分类严格按课件原文。

介质类别主要作用（后果）对应临床现象
组胺颗粒内预先形成小血管扩张、通透性增加；平滑肌收缩；腺体分泌增强荨麻疹、鼻炎喷嚏流涕、支气管痉挛、早期休克
激肽原酶颗粒内预先形成作用于血浆激肽原生成缓激肽→平滑肌收缩、血管扩张通透、刺激痛觉参与过敏性反应的血管与痛觉症状
嗜酸粒细胞趋化因子颗粒内预先形成趋化嗜酸粒细胞至反应局部晚发相嗜酸粒细胞浸润的基础之一
白三烯（LT）活化后新合成作用较组胺慢但强而持久，强烈收缩支气管平滑肌、增加血管通透、黏液分泌过敏性哮喘持续气道痉挛的重要介质
前列腺素 D2（PGD₂）活化后新合成血管扩张、支气管收缩、促炎参与鼻炎、哮喘与炎症
难点突破 ①：为什么“预先形成”的介质决定反应够快？

颗粒内的组胺等介质是早就造好、存着待用的，受体一被桥联即刻释放——这就是 Ⅰ 型“数分钟至数小时”急性爆发的物质基础（对比：Ⅳ 型需要新合成与募集细胞，故慢）。

难点突破 ②：新合成介质与“反应迁延”

白三烯、PGD₂ 需在激活后经膜脂代谢重新合成，释放更慢但效应更强更持久（尤其白三烯强而持久地收缩支气管）——它们是新一类抗过敏药（抑制介质合成与释放）的靶点之一，模块四再讲。

⏳ 2.5 早发相与晚发相：一场反应为何能“持续”数小时

以下为免疫学教材公共知识的机制放大描述（课件定义中的“数分钟至数小时”正是两相的宏观表现）。

早发相（即刻相，约 5–30 分钟达峰）

  • 由颗粒内预先形成介质（组胺等）主导
  • 表现：血管扩张/通透、平滑肌收缩、腺体分泌——来得快，消退也较快
→

晚发相（2–8 小时后，可迁延 24 h+）

  • 由新合成介质（LT、PGD₂）与被募集来的炎症细胞（嗜酸粒细胞、中性粒细胞、Th2 细胞等）主导
  • 表现：局部水肿、黏膜慢性炎症、组织损伤——是慢性过敏性鼻炎/哮喘迁延不愈的重要背景
一图看懂时间线

再次接触变应原 → 数分钟内组胺等“旧弹药”开火（早发相）→ 数小时后 LT/PGD₂“新弹药”与嗜酸粒细胞等“援军”接续（晚发相）。临床“先打喷嚏流涕，随后鼻塞持续大半天”的时间错落，正是两相叠加的结果。

🧠 2.6 小结与自检

本模块知识地图

致敏阶段（初次接触 → B 细胞产 IgE → 结合 FcεRI → 待命）→ 激发（再接触 → IgE 桥联）→ 效应（脱颗粒 → 介质 → 病理改变）。介质分预先形成（组胺/激肽原酶/ECF）与新合成（LT/PGD₂）；时间上对应早发相/晚发相。下一模块看这些机制在临床上“长什么样”。

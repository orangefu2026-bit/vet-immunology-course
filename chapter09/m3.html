Module 3 · 临床表现与个体差异

模块三：临床上常见的Ⅰ型反应

模块二讲清了“怎么引爆”，这一模块看“炸在不同部位有什么后果”，并用“青霉素为什么两次用药才出事”作为贯通第一章—本章的经典案例；最后回答“为什么偏偏是我过敏”。

学习目标对应介质回看 M2休克为急症提醒

🎯 学习目标卡

  • 能说出过敏性休克、过敏性鼻炎/哮喘、荨麻疹、食物过敏各属 Ⅰ 型反应的哪种“靶部位表现”
  • 能用“半抗原→完全抗原”解释青霉素为何可致过敏性休克（回扣第一章）
  • 能说明 Ⅰ 型反应的个体差异来自“遗传素质 × 环境暴露”，不把过敏归咎于“体质差”

🗂️ 3.1 总览：变应原“进门”途径 → 靶器官 → 疾病

同一种机制（IgE + 脱颗粒），因变应原进入途径与靶器官不同而表现各异；介质作用“血管扩张/通透、平滑肌收缩、腺体分泌”在全身各处被“读”成不同症状。

变应原途径主要靶部位常见表现课件依据
注射 / 药物全身（血管床）药物过敏性休克课件“临床常见Ⅰ型”页
吸入呼吸道过敏性鼻炎、过敏性哮喘课件“临床常见Ⅰ型”页
食入消化道 + 皮肤等食物过敏（呕吐腹泻、口唇/皮肤症状等）食物变应原（课件变应原分类）→ 教材公共知识展开
接触 / 皮肤皮肤荨麻疹（风团）、血管性水肿等教材公共知识（Ⅰ型典型皮肤表现）
急救提醒（公共应急常识）

过敏性休克属临床急症，可危及生命。处置要点是：立即停用并远离可疑变应原、保持气道通畅并就近急救，尽快使用肾上腺素等抗休克药物（药物清单见 模块四 4.4）。本网站只讲免疫学原理，不替代执业兽医与急救指南的现场处置。

🆘 3.2 药物过敏性休克：以青霉素为例（本章重点案例）

青霉素的“两步变身”（课件原文）

青霉素本身无免疫原性；它在弱碱环境中易降解为青霉噻唑醛酸，与体内大分子蛋白结合后才组合为完全抗原，从而能诱导 IgE、致敏机体。

图 3-1 青霉素“两步变身”完全抗原（课件原文）：这也解释了第一章“半抗原 + 载体”为何是理解兽药/人药过敏的钥匙。
  • 为什么多见于“第二次”用药？——第一次用药完成了“半抗原→完全抗原→诱导 IgE→致敏”的全过程（多数人无症状）；第二次再接触才“扣扳机”爆发，且发作急、可在数分钟内出现血压骤降、呼吸困难等全身性反应；
  • 临床对策：用药前询问过敏史、按规程做变应原（青霉素）皮试，对皮试阳性者改用其他类抗生素（回扣模块四防治 4.1/4.2）。

🌬️ 3.3 呼吸道过敏反应：过敏性鼻炎与过敏性哮喘

课件原文：吸入花粉、尘螨、真菌、动物毛屑等变应原引起的呼吸道过敏反应，表现为过敏性鼻炎、过敏性哮喘。

过敏性鼻炎（“上气道”）

  • 发作性喷嚏、流清涕、鼻塞鼻痒
  • 组胺使鼻黏膜血管扩张、腺体分泌增强是主要推手（早发相典型）

过敏性哮喘（“下气道”）

  • 支气管平滑肌痉挛 + 黏液分泌 → 喘息、呼吸困难
  • 组胺致急性痉挛；白三烯介导的持续痉挛与晚发相炎症使哮喘迁延
回扣机制

为什么吸入性变应原“偏爱”攻击呼吸道？——因为鼻咽、气管黏膜下正是 IgE 产生部位与肥大细胞富集区（模块一 1.6/1.7）；“战场设在门口”，吸入的变应原就地引爆。宠物医院里，动物对尘螨、花粉的过敏也常表现为瘙痒性皮肤病与呼吸道症状，是同一机制在不同物种的“翻译”。

🍽️ 3.4 皮肤与消化道表现：荨麻疹与食物过敏

食物变应原（牛奶、鸡蛋、鱼虾、蟹贝）为课件所列举；以下表现属免疫学教材公共知识的 I 型典型形态。

荨麻疹（风团）与血管性水肿

  • 皮肤真皮浅层小血管扩张、通透性增加→局部水肿隆起（风团），伴瘙痒
  • 可因食物、药物、昆虫叮咬等诱发，来去较快
VS

食物过敏（消化道型）

  • 进食后出现恶心呕吐、腹痛腹泻等胃肠道反应
  • 可同时伴皮肤（荨麻疹）与呼吸道症状；严重者可进展为全身反应
给兽医视角的一句话

犬猫的食物不良反应中，一部分属免疫介导（含 IgE/非 IgE 参与）——诊疗核心同样是“查明并规避变应原 + 必要时的药物/脱敏”，不能靠“换着吃”碰运气。规范诊疗路径见 模块四 4.6 与 案例教学。

🧬 3.5 遗传与个体差异：为什么“偏偏是我”？

同样养猫、同样吃虾，反应天差地别——因为 Ⅰ 型过敏是“遗传素质 × 环境暴露”的乘积（以下为免疫学教材公共知识）。

特应性素质（遗传）

部分个体有家族性“过敏倾向”（特应性，atopy）：易对环境中常见无害变应原产生 IgE。这与免疫调节的遗传背景、易向 Th2 型应答偏移有关。

免疫走向（Th2 / IL-4）

IgE 产生依赖 IL-4。当个体对某变应原的应答“偏向 Th2—IL-4—IgE”时，就更容易完成致敏（衔接第五、八章）。

环境与接触史

是否接触过该变应原、何时第一次接触、接触剂量与途径、是否处于感染或用药期间等，共同决定“会不会致敏、何时爆发”。

一个正在被研究的“假说”（不是定论）

免疫学界有“卫生假说”：儿童早期生活环境中微生物刺激减少，可能使免疫平衡偏向 Th2，与过敏性疾病增多相关。此说仍处于研究讨论中，只作为理解“为什么过敏越来越多”的一种科学假说，不作为确定病因（想深入了解可查阅公开综述文献）。

课堂讨论（开放）

同窝的猫，一只对食物添加剂起疹子、另一只安然无恙——请用“遗传素质 + 免疫走向 + 接触史”三个词给主人做一次科普。试一试，这比直接说“它就是过敏体质”专业得多。

🧠 3.6 小结与自检

本模块知识地图

按变应原途径—靶器官记住四组：注射→过敏性休克；吸入→过敏性鼻炎/哮喘；食入→食物过敏；皮肤→荨麻疹。核心案例如 青霉素：半抗原→弱碱降解→青霉噻唑醛酸→＋蛋白→完全抗原→致敏→再用药休克。个体差异=特应性遗传 × Th2/IgE 走向 × 环境接触史。下一模块回答“查出过敏之后怎么办”——进入防治与兽医临床。

模块自测M3 · Q1
青霉素在弱碱环境下降解产物与体内大分子蛋白结合后成为：
选 B。青霉素本身无免疫原性（半抗原），弱碱降解为青霉噻唑醛酸后与体内蛋白结合为完全抗原，才能诱导 IgE 导致致敏（课件原文，图 3-1）。
复习 3.2 青霉素机制
模块自测M3 · Q2
某人第一次注射青霉素后立即发生休克，说明青霉素的免疫原性极强，首次接触即可直接致敏发病。
错误。过敏性休克发生在“再次接触”时；所谓“第一次”往往意味着既往曾通过其他途径（如口服、皮试、含青霉素食物）完成过致敏，或由交叉反应性物质致敏。真正首次无致敏史的个体不会首次即休克。

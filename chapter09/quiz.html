单选1 / 14 · 概念
Ⅰ 型超敏反应（过敏反应型）主要由下列哪种抗体介导？
选 B。Ⅰ 型超敏反应由抗体 IgE 介导，故称过敏反应型；IgE 具亲嗜性，可与肥大细胞/嗜碱性粒细胞表面 FcεRI 结合。
对应：模块一 1.3 → 去复习
单选2 / 14 · 变应原
下列属于课件列举的“吸入性变应原”的是：
选 B。花粉颗粒、尘螨、动物皮屑属吸入性变应原（呼吸道途径）；青霉素、普鲁卡因属药物/化学物质类；鸡蛋属食物变应原。
对应：模块一 1.5 → 去复习
判断3 / 14 · 药物过敏
青霉素本身无免疫原性；它在弱碱环境中降解为青霉噻唑醛酸，与体内大分子蛋白结合后才成为完全抗原。
正确（课件原文）。青霉素是半抗原，需降解为青霉噻唑醛酸并与体内蛋白结合成完全抗原才能诱导 IgE、致敏机体——这是“第一次没事、第二次出事”的分子基础。
对应：模块三 3.2 → 去复习
单选4 / 14 · 致敏阶段
变应原初次进入机体后，使机体进入“致敏状态”的关键事件是：
选 C。致敏阶段=产生 IgE（依赖 IL-4）并“安装”到 FcεRI 上，机体处于待命状态、不表现症状；脱颗粒要等第二次接触才发生。
对应：模块二 2.2 → 去复习
单选5 / 14 · 激发阶段
变应原再次进入机体后，引发致敏靶细胞“脱颗粒”的直接触发条件是：
选 A。变应原与表面 IgE 特异性结合并使相邻受体桥联→激活信号→脱颗粒释放生物活性介质（课件机制原文；补体溶解靶细胞属 Ⅱ 型机制）。
对应：模块二 2.3 → 去复习
单选6 / 14 · 介质分类
下列属于肥大细胞颗粒内“预先形成”介质的是：
选 A。颗粒内预先形成介质：组胺、激肽原酶、嗜酸粒细胞趋化因子；白三烯与 PGD₂ 属活化后新合成介质（课件分类）。
对应：模块二 2.4 → 去复习
判断7 / 14 · 介质分类
白三烯（LT）和前列腺素 D2（PGD₂）属于肥大细胞被激活后“新合成”的生物活性介质。
正确。白三烯、PGD₂ 需在细胞活化后经膜脂代谢新合成，释放较慢但作用强而持久（白三烯强而持久收缩支气管）。
对应：模块二 2.4 → 去复习
多选8 / 14 · 效应环节
肥大细胞脱颗粒释放的组胺等介质作用于效应组织后，可引起哪些改变？
选 A、B、C。介质引起血管扩张/通透性增加、平滑肌收缩、腺体分泌增强——这些生理紊乱正是“过敏症状”的来源；D 错，Ⅰ 型反应并非有效清除变应原，反而造成病理损伤（友军误击）。
对应：模块二 2.3/2.4 → 去复习
单选9 / 14 · 呼吸道过敏
吸入花粉、尘螨、真菌、动物毛屑等变应原，主要引起哪一类 Ⅰ 型超敏反应表现？
选 B（课件原文）。吸入性变应原→呼吸道过敏反应（过敏性鼻炎、哮喘）；溶血与免疫复合物病分属 Ⅱ、Ⅲ 型。
对应：模块三 3.3 → 去复习
单选10 / 14 · 防治
某动物必须使用马源破伤风抗毒素，但皮试阳性（已致敏）。规范的做法是：
选 C。异种血清脱敏疗法以少量、多次、短间隔递增给药诱导耐受，在保障必需治疗的同时控制过敏风险；A 直接全量注射风险极高，D 无免疫学依据。
对应：模块四 4.3 → 去复习
判断11 / 14 · 脱敏原理
脱敏治疗（特异性脱敏）的基本思路是长期小剂量、多次递增给予变应原，诱导机体产生耐受或降低反应强度，而不是“一次给足变应原”。
正确。脱敏=把“一次大量→爆发”改写为“长期小剂量→驯服引信”；“一次给足”反而会诱发严重反应，必须在专业人员监护下实施。
对应：模块四 4.3 → 去复习
单选12 / 14 · 药物防治
苯海拉明、扑尔敏等组胺拮抗药物缓解 Ⅰ 型过敏症状的机制是：
选 B。组胺拮抗药（H1 受体拮抗剂）在“受体端”挡回组胺的作用，缓解荨麻疹、鼻炎等以组胺为主的症状；它不减少 IgE、不中和变应原。
对应：模块四 4.4 → 去复习
判断13 / 14 · 阶段时序
Ⅰ 型超敏反应的爆发发生在变应原“初次进入”机体时；只要既往从未接触该疫苗成分，接种后 30 分钟内就绝无可能发生速发型过敏。
错误。速发型过敏发生在“再次接触”（已致敏者）；但“从未接种过该疫苗”不等于“从未接触过该成分/交叉反应物”，且皮试、残留蛋白等既往暴露都可能完成致敏——所以接种后仍应按规定留观。
对应：模块二 2.2/2.3 + 模块四 4.6 → 去复习
情境 · 不计分14 / 14 · 迁移应用
一位养猫的朋友向你诉苦：“我对猫毛过敏，打喷嚏、起疹子，可我又舍不得送走它。”作为兽医专业学生，请你用本章知识给她写一份 200 字左右的建议：① 解释她“为什么会过敏”（机制）；② 给出诊断与防治的思路（至少两条，提示：查明变应原、避免/减少接触、脱敏、特异性免疫治疗、药物）。
参考思路（开放题，言之成理即可）：① 机制：猫皮屑/唾液中的变应原（如 Fel d 1）初次接触使其致敏（IgE 结合肥大细胞 FcεRI），再次接触即桥联脱颗粒→组胺等介质→喷嚏、荨麻疹（可对比“为何别人没事”：遗传素质+免疫走向差异）。② 防治：先去变态反应专科/宠物医院做变应原筛查确认主犯（皮试/血清特异性 IgE）；之后组合施策——减少接触（猫不进卧室、勤清洁、空气净化），必要时药物（抗组胺药缓解急性症状），希望长期改善可与医师讨论脱敏治疗；产业上已有抗 Fel d 1 抗体（疫苗诱导/IgY 猫粮）等方向降低变应原负荷（课件方向，以最新产品信息为准）。
综合：模块一 三要素 + 模块二 机制 + 模块三 表现 + 模块四 防治 → 去复习

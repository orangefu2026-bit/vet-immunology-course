🗂️ 2.1 方法谱系总览：按“信号怎么来”分类

不按“谁发明的”记，按“信号从哪来”记，方法就串起来了。

大类代表方法信号怎么来主要用途
经典血清学反应（不用标记物）凝集反应、沉淀反应（含琼脂扩散）抗原—抗体结合后，反应体系自身“结块 / 出现沉淀环”，肉眼直接观察细菌鉴定与分型、血清抗体检测（如布病、鸡白痢、血凝抑制试验）
免疫标记技术（借助标记物）固相酶免疫：ELISA；组织定位：免疫荧光 / 免疫组化；蛋白确认：免疫印迹；定量：化学发光免疫分析酶催化底物显色、荧光素发光、发光物发光……把“结合”放大成可读信号病毒 / 细菌抗原与抗体定量或半定量检测、病原蛋白鉴定、组织定位
免疫层析快检（可视化 POCT）：胶体金试纸条、量子点 / 荧光微球试纸条（模块三、四详讲）胶体金 / 荧光颗粒在硝酸纤维素膜上聚集显色现场、快速、无需仪器判读，基层与临床一线筛查
记忆锚点

“结块” = 凝集沉淀（经典）；“显色 / 发光” = 标记技术（现代）；“一条膜上跑出来的显色” = 免疫层析（快检）。三种信号形态对应三类战场侦察工具。

🫧 2.2 经典血清学反应：凝集反应与沉淀反应

凝集反应

  • 定义：颗粒性抗原（细菌、红细胞等）与相应抗体结合，形成肉眼可见的凝集块。
  • 直接凝集：细菌 / 红细胞本身 + 抗体。兽医应用例：布病虎红平板凝集试验、鸡白痢全血平板凝集等血清学筛查。
  • 间接（被动）凝集：可溶性抗原先吸附到惰性载体（乳胶、红细胞）上，再与抗体凝集，可放大灵敏度。
  • 血凝 / 血凝抑制（HA / HI）：用“病毒凝集红细胞 / 抗体抑制其凝集”间接测抗体，是流感病毒等抗体监测的常用手段。

沉淀反应

  • 定义：可溶性抗原（蛋白、多糖等）与相应抗体结合形成沉淀（环、线、带）。
  • 环状沉淀：抗原溶液叠加于抗血清上，界面出现沉淀环（如炭疽 Ascoli 试验等经典应用）。
  • 琼脂扩散（双向扩散）：抗原与抗体在琼脂中相向扩散，相遇处形成沉淀线；可用于抗原分析 / 血清抗体检测。
  • 免疫电泳：先电泳分离再扩散沉淀，用于分析抗原组成。
理解要点：经典方法的“放大”逻辑

经典方法不借助标记物，靠的是抗原—抗体按比例结合形成大分子网络（晶格），网络大到肉眼可见（凝集 / 沉淀）。它的优点是简单、廉价、便于基层；局限是灵敏度相对有限、主要看“半定量”，对痕量病毒蛋白等“小敌情”常常力不从心——于是免疫标记技术登场。

🚩 2.3 免疫标记技术：标记物 = 信号旗

把“认得病毒 / 抗体”的元件装上信号旗，让结合“亮起来”——这是现代免疫检测的主流。

标记物信号形式常见检测体系特点
酶（辣根过氧化物酶 HRP、碱性磷酸酶等）催化底物显色（如 TMB 呈蓝→黄）ELISA、免疫印迹信号放大能力强（一个酶分子可催化大量底物），定量成熟，需配套仪器 / 洗板
荧光素（FITC 等）激发后发射荧光免疫荧光（直接 / 间接）适合组织与细胞原位定位
胶体金颗粒聚集呈红色免疫层析试纸条（模块三）肉眼判读、无需仪器，最适合现场快检
化学发光物（鲁米诺 / 吖啶酯等）化学反应发光化学发光免疫分析灵敏度高、可自动化高通量定量
量子点 / 荧光微球强荧光（粒径依赖、光稳定性好）新一代免疫层析（模块四实验室成果）比胶体金更灵敏，为“可视化检测”升级方向

同位素标记（放射免疫分析 RIA）灵敏度极高，但因放射防护与废弃物管理要求，现代兽医检测中已多被酶 / 发光等技术替代（公开教材公共知识）。

🧪 2.4 ELISA——最常用的酶联免疫吸附试验

难点突破区：为什么 ELISA 能“检出看不见的病毒 / 抗体”？

ELISA（Enzyme-Linked Immunosorbent Assay，酶联免疫吸附试验）

把抗原或抗体固定在固相载体（微孔板）表面，用酶标记的抗体 / 抗原作探针，最后加入底物显色。颜色深浅与待检物含量相关——这就是“让病毒 / 抗体现形”的关键一步：酶把一次免疫结合“放大”成千千万万个显色分子，肉眼和酶标仪就读得出来了。

按“测什么、怎么设计”，ELISA 主要有四种模式：

模式检测对象设计要点典型兽医应用
直接 ELISA抗原固相包被待检抗原，加入酶标特异性抗体直接结合、显色病原抗原的直接检测（步骤少、交叉少）
间接 ELISA抗体固相包被已知抗原 → 加待检血清（其中的抗体结合）→ 加酶标抗抗体（二抗）显色疫苗免疫抗体水平监测、流行病学血清学调查
双抗体夹心 ELISA大分子抗原固相包被“捕获抗体”捕获抗原 → 加“检测抗体”夹住 → 酶标二抗显色病毒（如 PEDV、禽流感等）抗原检测
竞争 ELISA小分子（半抗原类）样品中未标记抗原与酶标抗原竞争结合有限抗体，信号与含量成反比兽药残留（磺胺、抗生素等小分子）检测
快问：间接 ELISA 中“二抗”是干什么的？

待检血清里的抗体（一抗）来自被测动物，没法直接显色；酶标二抗是“抗这种抗体恒定区的抗体”（如酶标抗猪 IgG），专门识别并结合一抗，从而把“动物有没有针对某病原的抗体”变成颜色信号。——注意：这与模块三试纸条质控线“抗抗体拦截金标抗体”是同一类免疫学设计（抗抗体识别一抗恒定区）。

为什么 ELISA 能检出“看不见”的病毒？——本节答案

① 认得：固相上的抗体 / 抗原与样品中的目标病毒蛋白特异性结合；② 留住并洗去：洗板除去未结合的杂质（背景噪音）；③ 放大：酶标探针 + 底物，把每个结合事件催化放大为显色分子；④ 读数：颜色深浅 → 阳性 / 阴性或定量。看不见的分子事件，被“酶”这台放大器变成了看得见的光密度值。

🔦 2.5 免疫荧光、免疫印迹与化学发光：各有各的战场

技术一句话原理看什么 / 用在哪
免疫荧光（IF）荧光素标记抗体，在组织 / 细胞上特异性结合，荧光显微镜下发光定位组织切片中病原抗原定位（如病毒感染组织）、细胞染色；直接 / 间接两种标记法
免疫印迹（Western blot）SDS-PAGE 分离蛋白 → 转膜 → 特异性抗体识别 → 酶标二抗显色出条带确认“针对某特定蛋白抗原”的抗体（分子量 + 特异性双重证据），是 ELISA 阳性结果的补充确认手段
化学发光免疫分析标记物在反应中化学发光，光信号强度与待检物成正比自动化、高通量的定量检测（人医检验已普及，正向动物疫病高通量监测平台延伸）
方法选择的一句话决策（可贴在你的笔记里）

要快、要现场、要便宜 → 胶体金试纸条（免疫层析，模块三）；要测抗体定量 / 批量筛查 → 间接 ELISA；要测大分子病原抗原 → 双抗体夹心 ELISA 或层析快检；要测兽药残留等小分子 → 竞争 ELISA；要组织定位 → 免疫荧光；要确认某条蛋白带 → 免疫印迹；要高通量定量 → 化学发光。

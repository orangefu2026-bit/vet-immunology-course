1｜量子点：给“可视化检测”换一杆更亮的信号旗

2023 年诺贝尔化学奖授予蒙吉·巴文迪（Moungi Bawendi）、路易斯·布鲁斯（Louis Brus）与阿列克谢·叶基莫夫（Alexei Ekimov），表彰其发现并合成了量子点。量子点是纳米级半导体晶体，粒径决定荧光颜色、亮度高且光稳定性好。与本章的联系：量子点正作为新一代标记物替代 / 补充胶体金——模块四课件“实验室成果”的母乳 PEDV sIgA 检测试纸条即采用了量子点（符合率 95.79%），这正是“标记物家族”（模块二）在产业化中的直接延伸。

来源：诺贝尔奖官网 nobelprize.org（2023 年化学奖）；本章课件“实验室成果”页

2｜多联检与微阵列：一个样品，多份“情报”

免疫层析正在从“一条纸条测一个指标”走向多重检测：一条膜上设多条检测线（或多个孔道），一次加样同时报告多种病原 / 多个指标；蛋白与抗体微阵列把成百上千个识别点放在一张芯片上，实现高通量筛查。与本章的联系：它把模块三“T 线 / C 线”的判读体系扩展为“多 T 线 / 阵列读点”，本质仍是“特异性结合 + 标记信号”，但把“一份情报”升级为“一张情报网”。

来源：公开学术综述概念（免疫层析多联检 / 微阵列 POCT 技术方向，本页仅作方向性介绍，非考点；如需引用请查阅近年综述原文核实）

3｜数字读卡 + AI 判读：把“人眼”交给算法复核

便携读卡仪与手机拍照判读已开始用于试纸条结果：在规定时间拍摄 T / C 线，由算法判断强弱并留档上传，避免肉眼判读的主观差异与“判读超时”误差。与本章的联系：模块三强调“C 线质控 + 规定时间内判读”，数字化读卡正是用设备把这两条纪律固化成流程；结果可记录、可追溯，也让模块四“监测数据化”成为可能。

来源：公开产品与技术综述（数字化 POCT 方向，定性介绍，非考点）

4｜免疫分析自动化：从“一人一板”到高通量平台

人类医学检验中，化学发光 / 电化学发光等自动化免疫分析已成为主流，实现大批量样品的连续进样、自动加样、自动判读与报告。与本章的联系：模块二讲过“化学发光免疫分析”的定量优势，模块四的抗体监测（如疫苗免疫效果评价、疫病净化筛查）面对“成千上万份血清”，正是这类自动化高通量平台的应用场景——动物疫病大规模血清学监测的自动化是明确的行业方向。

来源：公开技术综述 / 检验医学教材公共知识（定性描述，非本课件承诺；具体平台与性能以厂商与文献为准）

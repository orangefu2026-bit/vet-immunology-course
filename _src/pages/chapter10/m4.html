🛠️ 4.1 试剂盒研发：一条可复制的技术路线

课件给出了从“蛋白”到“试纸条”的完整流程图，四段式记住它。

① 蛋白原核表达先把“鱼饵”造出来质粒构建 → 诱导表达 → 蛋白纯化 → 蛋白浓缩（获得重组抗原）
→
② 检测方法建立组装“钓竿”标记物（量子点 / 荧光微球）与抗体偶联 → 优化 NC 膜抗原包被浓度 → 试纸条组装 → 确定阴阳性诊断标准
→
③ 方法学评价证明它“测得准”特异性评价 · 敏感性评价 · 重复性评价（是否受其他病原干扰？弱阳性能否检出？批间批内稳定吗？）
→
④ 临床样品检测拿到现场去验证用真实临床样品（如母乳、血清、拭子）检验，并与商品化试剂盒比对符合率
为什么“重组抗原 + 标记物”是研发的两大变量？

抗体检测试纸条的“金标物”是重组抗原——抗原表达得纯不纯、包被在膜上的浓度合不合适，直接决定 T / C 线会不会“打架”或“假阳”；而标记物（胶体金、荧光微球、量子点）决定信号的灵敏度与读法。所以路线图先做蛋白，再调方法，再评价，最后上临床——一步都不能跳。

🧪 4.2 实验室成果：母乳中 PEDV sIgA 抗体的可视化检测

（本页数据与文字均依据课件“创新应用举例”之实验室成果，不另添加课件之外的数据。）

研究背景（课件）

猪流行性腹泻病毒（PEDV）是危害新生仔猪的病原之一。仔猪出生后主要依靠母乳（初乳与常乳）中的抗体获得被动免疫，其中分泌型 IgA（sIgA）是乳汁黏膜免疫的关键抗体。若能快速检测“母乳里的 PEDV sIgA”，就可以便捷评估母猪的免疫状态 / 母源保护水平，为免疫程序调整提供依据。

课程团队（课件“实验室成果”）分别以荧光微球与量子点为标记物，组装了两款 PEDV sIgA 抗体免疫层析试纸条，并在 100 份临床母乳样品上与商品化试剂盒做了比对：

怎么读这张结果表？（数据分析训练）

① 两款自研试纸条阳性检出率均为 95%，与商品化试剂盒检出率（88% / 91%）相当甚至更高，且符合率分别达 92.63% 与 95.79%（课件注明符合率均在 90% 以上 / 95% 以上）——说明新方法结果可靠、可作替代或互补工具；② 阳性检出率与符合率都接近但不等同，剩余差异提示：不同方法“判定阈值”与“假阳 / 假阴”取舍不同，这正是 4.3 节要讲的方法学评价；③ 量子点方案符合率更高，呼应其灵敏度 / 光稳定性优势（模块二标记物家族）。

⚖️ 4.3 方法学评价与质量控制：它“测得准”吗？

难点突破：灵敏、特异、假阳、假阴——检测结果的“四道安检”。

指标含义通俗说法
敏感性（灵敏度）能正确检出已知阳性样品的能力（真阳性检出比例）“有敌情能不能发现”
特异性对已知阴性样品正确判阴的能力（真阴性判阴比例）“不是目标物会不会误报”
重复性同一样品多次 / 多批检测结果一致（批内、批间）“换个人、换一盒还一样吗”
符合率与参考方法（如商品化试剂盒）结果一致的比例“跟老裁判判得一样吗”

假阳性（误报“有”）

  • 交叉反应：与其他病原共享表位 / 抗原不纯
  • 非特异性吸附、样品污染、判读超时
  • 后果：把阴性当阳性 → 错检，误淘汰 / 误扑杀
VS

假阴性（漏报“没有”）

  • 灵敏度不足：抗原 / 抗体量低于检出限（感染极早期）
  • 试剂失效（C 线缺失）、操作不当、样品质量差
  • 后果：把阳性当阴性 → 漏检，疫情扩散
质量控制的“组合拳”（试剂盒设计 + 使用两端）

设计端：每张纸条设质控线 C（试剂自检）；配阴阳性对照 / 内置质控品；选择特异性强的抗体、优化包被浓度；出厂做灵敏度、特异性、重复性检验。使用端：规范采样与保存；在规定时间内判读；可疑结果（T 线极浅、C 线异常）用同盒复测或换方法（如 ELISA / 实验室复核）确认。这与课件“不能慢检、不能漏检、不能错检”的要求一一对应。

🏥 4.4 试剂盒在动物疫病监测中的应用图谱

诊断试剂盒按“要回答什么问题”分成三类用途——先选目标，再选方法。

检测目的回答什么问题常用方法举例（本章知识）典型监测场景
病原抗原检测体内现在有没有病原双抗体夹心 ELISA、胶体金试纸条（抗原模式）感染早期筛查、发病群病原确认
抗体检测是否感染过 / 免疫应答如何间接 ELISA、抗体检测试纸条（如 PEDV sIgA）、血凝抑制试验疫苗免疫效果评价、母源抗体监测、流行病学调查
病原（微生物学 / 分子）鉴定是哪种病原 / 哪个型分离培养、分子生物学方法（与免疫检测互补，属实验室确诊环节）疫病确诊、疫情定性
应用思路题（口头回答）

净化一个“无疫苗可用”的病（如课件提到的禽白血病）：先测抗原还是先测抗体？为什么扑杀决策要“检测—淘汰—扑杀”反复多轮？

参考思路（先自己答再看）

要“把阳性带毒个体清出去”，关键是找到正在排毒 / 带毒的个体 → 首选用抗原检测反映现症感染；抗体检测可辅助流行病学回溯。净化需多轮检测，因为存在窗口期漏检、重复感染与检测误差（假阴假阳），必须反复筛查直到群体阴性稳定——这就是“不能漏检、不能错检”的实操含义。

新型检测趋势速览（非考点 · 拓展视野）

① 可视化升级：荧光微球、量子点替代胶体金，把“肉眼判读”升级为“读数更灵敏”的可视化（本页实验室成果即例）；② 多联检与阵列化：一张卡同时测多种病原 / 多个指标（多重检测、微阵列思路）；③ POCT + 数字化：小型读卡仪 / 手机拍照自动判读，让结果客观可留档；④ 与分子诊断互补：免疫快检做“初筛”，实验室方法做“确诊”，各司其职。详细来源见 学科前沿 页。

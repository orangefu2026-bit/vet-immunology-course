🧪 4.1 外毒素 → 类毒素 → 抗毒素：一条“以毒攻毒”的产线

原料外毒素细菌分泌的毒性蛋白质，有毒性与免疫原性
→
0.3%–0.4% 甲醛类毒素失去毒性、保留免疫原性 → 疫苗抗原
→
免疫马 → 采血抗毒素（血清）胃酶消化 + 纯化 → 用于预防和治疗
三个名词，一张表分清（高频考点）
制剂是什么用途免疫学要点
外毒素细菌分泌的毒性蛋白质（如破伤风痉挛毒素）研究原料；不可直接作疫苗毒性强 + 免疫原性强
类毒素外毒素经 0.3%–0.4% 甲醛处理：去毒性、保留免疫原性疫苗（主动免疫，如破伤风类毒素）免疫原性与毒性“分离”的典范
抗毒素类毒素免疫马所得血浆，经胃酶消化后纯化的抗体球蛋白制剂（课件原文）被动免疫：感染后的预防与治疗本质是抗体（中和外毒素）
课件思考题 2（本章主线问题再次出现）

“为什么要给畜禽打疫苗？打一种疫苗为什么不能预防所有的传染性疾病？”
学到这里你可以这样回答：疫苗=注入“安全的抗原情报”（如类毒素/灭活病原/亚单位抗原），让免疫系统预先练兵；而疫苗的“情报内容”各不一样——不同病原（甚至同种病原不同血清型）的表位不同，抗体认表位不认“病名”，所以必须“专病专防”。若一种疫苗同时含多种病原抗原（联苗），则是把多份情报合并在一次注射里。

易错提示

类毒素属于疫苗抗原（主动免疫）；抗毒素属于抗体制剂（被动免疫）——两者都“防破伤风”，但机制相反：一个让机体自己产生抗体，一个直接输入现成抗体。注射抗毒素后短期内不宜再接种相应类毒素疫苗（抗体可中和疫苗抗原），临床要记住间隔原则。

补充对比：内毒素

革兰氏阴性菌细胞壁的脂多糖（LPS）为内毒素，与“外毒素”对应：化学本质为脂多糖而非蛋白质、耐热、毒性主要来自过量释放引起的全身反应，免疫原性较弱，甲醛处理不能使其成为类毒素。所以“类毒素”特指蛋白质外毒素的改造产物——这一区分在生物制品学中很关键。

🧬 4.2 基因工程抗原：把“抗原工厂”搬进细胞

课件给出了完整技术路线与优势，先看优势再走流程。

基因工程抗原的优势（课件原文要点）

  • 能轻易地克隆特定蛋白，批量化生产纯度较高的蛋白；
  • 能大量生产少见的天然抗原（如基因突变导致的氨基酸改变）；
  • 能给特定蛋白添加标签（便于纯化与检测）。
图 4-1 基因工程抗原技术路线（依据课件“基因工程抗原”页）：基因克隆 → 表达载体 → CHO 细胞表达 → 抗原纯化 → 质检与佐剂配伍。课件以“新冠病毒 S 蛋白抗原基因设计与克隆”为例展示该平台。
为什么重组抗原常常需要佐剂？

纯化蛋白抗原免疫原性相对弱（没有病原体的“危险信号”辅助），佐剂（adjuvant）能非特异增强免疫应答。疫苗设计的“抗原 + 佐剂”双轮，将在第十一、十二章系统学习。先记住：抗原决定“打谁”，佐剂决定“打多响”。

🔬 4.3 VLP 病毒样颗粒疫苗：当“外壳”成为抗原（含实验室成果）

为什么 VLP 是“好抗原”？——回扣模块二的构象表位

病毒样颗粒（VLP）= 病毒结构蛋白自组装成的“空壳”，不含核酸、不能复制（无感染性），但表面保留了与天然病毒相似的构象表位，免疫原性好。它同时满足疫苗两大要求：像真病毒（免疫系统认得）＋ 安全（不会致病）——是“构象表位完整 + 无感染性”的典型答案。

📌 实验室成果（课件“PEDV 与 TGEV ADDomer 病毒样颗粒疫苗免疫研究”）

背景：猪流行性腹泻病毒（PEDV）与猪传染性胃肠炎病毒（TGEV）引起新生仔猪严重腹泻，是养猪业重大经济损失来源，急需安全高效的疫苗抗原平台。

做法：提取细菌或病毒结构中的有效抗原进行表达，加入佐剂制备成疫苗（课件“①—④”流程：制备 → 免疫 → 效果评估）。

评价指标（课件列出，正好复习免疫应答“读表”）：外周血 PEDV 特异性 IgG、抗 PEDV 中和抗体（体液免疫）；外周血 IFN-γ、CTL 活性（细胞免疫）。
——为什么既要测抗体又要测 IFN-γ/CTL？因为理想疫苗要同时调动体液与细胞免疫两条战线（衔接第五、八章）。

情境思考（小组讨论 5 分钟）

某疫苗企业想开发“猪圆环病毒 2 型（PCV2）”疫苗，候选方案：① 灭活全病毒；② 重组 Cap 蛋白 + 佐剂；③ Cap 蛋白 VLP。请从抗原构象完整性、生产成本、安全性三方面比较并给出你的选择理由（先讨论再展开答案）。

参考思路

③ VLP 兼具构象表位完整（类似天然病毒，利于中和抗体）与无感染性（安全），且可通过表达系统规模化生产——是亚单位疫苗的热门方向；① 构象最全但需灭活与生物安全防护；② 生产简便但单体蛋白构象表位往往不如 VLP 完整，常需更强调佐剂。实际选型还要考虑成本与佐剂配伍。

🧠 4.4 小结与自检

本模块知识地图

外毒素 → 类毒素（疫苗）→ 抗毒素（治疗）；内毒素弱免疫原性、不能类毒素化；基因工程抗原（克隆—表达—纯化—质检—佐剂）解决“量产纯净抗原”；VLP 实现“构象完整 + 安全”兼得。四个词串起来：安全、有效、量产、保构象——这是现代疫苗抗原设计的四把尺。

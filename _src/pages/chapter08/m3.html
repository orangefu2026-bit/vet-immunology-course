Module 3 · 抗体效应功能（二）

模块三：激活补体与 ADCC

抗体不能直接杀死细菌——但抗体能"呼叫火力支援"：一是拉响补体系统警报，让 MAC 在靶细胞膜上打洞（CDC）；二是呼叫 NK 细胞，借 NK 之手杀伤靶细胞（ADCC）。本模块是本章难点集中页，务必看清"借刀杀敌"的每一步。

本章难点含可视化利妥昔单抗（课件）

🎯 学习目标卡

  • 能复述课件观点"抗体不能直接杀死细菌，MAC 可以"，解释抗体与补体的分工
  • 能说出 CDC 的定义与步骤（抗体结合抗原 → 结合 C1q → 级联 → MAC 杀伤）
  • 能说出 ADCC 的定义（NK 细胞经 Fc 受体结合抗体 Fc 段 → 杀伤靶细胞）
  • 能以利妥昔单抗为例，说明 CDC 与 ADCC 如何"双通道"联合杀伤肿瘤 B 细胞

💥 3.1 难点突破：为什么抗体"不能直接杀死细菌"？

先建立一个关键前提，后面所有机制都不难记。

课件原话："抗体不能直接杀死细菌，MAC 可以"

抗体分子能做的，是特异性地"抓住"靶标并发出信号；真正在膜上"开洞"杀死细菌/细胞的，是补体系统的 MAC（膜攻击复合物），或是被抗体召来的细胞（吞噬细胞、NK 细胞）。

🧲 抗体：识别 + 信号兵

  • Fab 段特异性结合抗原
  • 结合后 Fc 段"暴露/构象变化"，可以：启动补体经典途径 / 结合吞噬细胞 Fc 受体 / 结合 NK 细胞 Fc 受体
  • 不直接裂解靶标
⟶ 火力交给

💣 帮手：真正执行杀伤

  • 补体 MAC：在靶膜上打孔 → 渗透裂解
  • 吞噬细胞：吞入并消化（模块二调理）
  • NK 细胞：释放穿孔素/颗粒酶杀伤（本模块 ADCC）
为什么这样设计更"聪明"？

把"识别"与"杀伤"分工，可以让有限的特异性抗体指挥多种广谱效应机制：一种抗体认准靶标后，可以同时调动补体、吞噬细胞、NK 细胞——相当于"一弹多导"。这也解释了为何许多抗体制剂（如单抗）能通过工程改造增强与效应机制的配合。

🧨 3.2 激活补体 → CDC：让 MAC 在靶膜上"开洞"

补体依赖的细胞毒性作用（CDC）——课件定义

抗原—抗体复合物，通过结合补体 C1q 成分，级联激活补体经典途径，形成 膜攻击复合物（MAC） 杀伤靶细胞或细菌，也称补体依赖细胞毒性作用（CDC）。

①形成复合物抗体（IgG/IgM）结合靶细胞/细菌表面抗原
→
②结合 C1q抗原抗体复合物暴露补体结合位点，C1 被活化（经典途径启动）
→
③级联活化C4→C2→C3→C5…逐级酶解放大
→
④形成 MACC5b-9 在膜上组装成孔道
→
⑤渗透裂解靶细胞肿胀裂解死亡
知识拓展（衔接第六章，非考点但值得知道）

课件第 9 页旁注"补体的发现：好奇心推动科学进步"——1880–1890 年代科学家注意到血清中"加热即失效"的杀菌成分，从而发现补体（complement，意为"补充"抗体作用的成分）。好奇心让一个"加热后血清为什么不杀菌"的小问题，打开了整个补体系统研究的大门。这与本页 CDC 机制一脉相承。

口头推理题

IgM 是五聚体，IgG 是单体——当它们都结合在细菌表面时，哪个更"省抗体"地启动经典途径？

参考思路（先自己推理再看）

IgM 五聚体含 5 个 Fc 区、一个分子结合即可有效结合 C1q 启动补体；IgG 需要多个分子聚集在靶表面才能有效结合 C1q。所以 IgM 激活补体的效率更高——这也是 IgM 在抗感染早期（初次应答先出现）的价值之一。

🎯 3.3 ADCC：呼叫 NK 特种兵，借刀杀靶

抗体依赖性细胞介导的细胞毒作用（ADCC）——课件定义

NK 细胞表面具有抗体分子 Fc 片段的受体。当抗体分子与相应靶细胞结合后，NK 细胞借助 Fc 受体与抗体分子的 Fc 片段结合，从而发挥其细胞毒作用杀伤靶细胞。

①抗体结合靶抗体 Fab 结合靶细胞表面抗原
→
②NK 识别NK 的 Fc 受体结合抗体 Fc 段（识别被抗体包被的靶）
→
③定向杀伤NK 释放穿孔素/颗粒酶等，杀伤靶细胞
比较项CDC（补体依赖细胞毒）ADCC（抗体依赖细胞介导细胞毒）
谁来"扣扳机"补体系统（经典途径 → MAC）NK 细胞等（经 Fc 受体）
杀伤方式MAC 在膜上打孔 → 渗透裂解穿孔素/颗粒酶 → 靶细胞裂解/凋亡
依赖抗体部位Fc 段暴露补体结合位点Fc 段被 NK 的 Fc 受体识别
作用对象细菌、靶细胞（肿瘤/感染细胞等）多为被抗体包被的靶细胞（肿瘤/病毒感染细胞）
记忆钩子

CDC = Complement（补体）；ADCC = Antibody（抗体）把效应细胞（Cell）拉来当杀手。二者都是"借刀杀敌"，只是借的"刀"不同。

🩺 3.4 联合战例：利妥昔单抗——CDC + ADCC 双通道杀伤肿瘤 B 细胞

利妥昔单抗的作用机制（课件原文要点）

利妥昔单抗由人源 IgG1 和鼠源 CD20 抗体可变区组成，能特异性结合 B 细胞表面 CD20。通过 CDC 形成 MAC 孔道、ADCC 激活 NK 细胞释放穿孔素/颗粒酶，双重途径裂解并诱导肿瘤 B 细胞凋亡。

拆解这个"嵌合单抗"：四个要点

  • 为什么"人源+鼠源"？ 鼠源可变区负责高亲和力结合 CD20（来自小鼠杂交瘤），人源 IgG1 骨架降低异源免疫原性、便于募集人的补体与 NK——"人源化/嵌合"是单抗工程的经典策略；
  • 靶点 CD20：B 细胞（含肿瘤性 B 细胞）表面标志，正常造血干细胞不表达——有选择性；
  • 双机制并行：CDC（补体打孔）+ ADCC（NK 杀伤）可叠加，增强清除；
  • 诱导凋亡：除裂解外还诱导肿瘤 B 细胞凋亡（课件）。
迁移思考（检验是否真懂）

如果利妥昔单抗的 Fc 段被改造得"不能结合补体 C1q、也不能结合 NK 的 Fc 受体"，它还能有效治疗 B 细胞淋巴瘤吗？为什么？

参考思路

疗效会显著下降。该药的核心机制就是"结合 CD20 后借 CDC 与 ADCC 清除肿瘤 B 细胞"；去掉 Fc 效应功能等于拆掉了它的两条"杀敌通道"。这从反面说明抗体 Fc 介导的效应功能在治疗中的重要性。

🧠 3.5 小结与自检

本模块知识地图

大前提：抗体不能直接杀菌 → CDC（抗体→C1q→经典途径→MAC 打孔）与 ADCC（抗体→NK Fc 受体→穿孔素/颗粒酶）都是"借刀杀敌" → 利妥昔单抗把两条通道装进一个分子：CDC+ADCC 双机制杀伤 CD20⁺ 肿瘤 B 细胞。遇到"抗体怎么杀死细胞"的问题，先答"识别→招募→打孔/颗粒酶"三步。

启发性问题（带着它进入模块四）

以上抗体都在"血液/组织"里作战。但绝大多数病原是从呼吸道、消化道、泌尿生殖道黏膜入侵的——黏膜表面靠谁防守？答案是分泌型 IgA（sIgA）。此外，抗体并非总是"友军"：用力过猛会造成免疫损伤。模块四为本章"收官"。

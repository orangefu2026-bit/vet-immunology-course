模块三：基因工程疫苗的研制

活疫苗免疫效果好，却有两个“先天烦恼”：分不清疫苗株与野毒株、担心毒力恢复。基因工程给了我们“手术刀”——基因缺失疫苗删掉毒力基因，基因工程活载体疫苗把病毒改装成“快递车”。本模块是本章难点（难点突破见 3.4）。

✂️ 3.1 基因缺失疫苗的研制原理

课件：明确病毒编码毒力基因 → 基因缺失去除毒力基因 → 获得基因缺失毒株。

图 3-1 基因缺失疫苗原理：把强毒株的毒力基因（如 CD2v、MGF）删除，得到“缺了獠牙”的减毒株作疫苗。
① 研究明确病毒编码毒力基因先弄清“哪个基因让它致病”
→
② 编辑基因缺失去除毒力基因用基因工程删除/敲除毒力相关基因
→
③ 获取获得基因缺失毒株减毒且保留复制与免疫原性
→
④ 生产培养、扩增、纯化与检测 → 制备疫苗同弱毒疫苗的规模化流程
为什么“删除毒力基因”还能顺便解决“身份难题”？

因为缺失的基因成为疫苗株的“身份标记”：野毒株有该基因，疫苗株没有。用针对“缺失基因的产物”做检测——抗体阳性 = 感染过野毒，抗体阴性 + 打疫苗 = 免疫成功。这就是“标记疫苗 + 鉴别诊断”的思路（难点突破 3.4 再展开）。

🔬 3.2 研究示例：非洲猪瘟基因缺失疫苗的探索（课件实验室成果）

课件实验室成果：ASFV 减毒活疫苗（基因缺失疫苗）免疫效果检测

疫苗制备思路：通过同源重组技术删除 ASFV 毒力相关基因（如 CD2v、MGF），获得基因缺失重组病毒，并在原代巨噬细胞中扩增，经 PCR 和测序验证后用于猪免疫与攻毒试验，评价其安全性和保护效果，筛选减毒活疫苗候选株。

结果：双基因缺失毒株 ASFV-HNΔCD2vΔMGF 虽具有良好安全性和减毒特性，但免疫后仅延迟发病，未能有效抑制病毒复制、排毒及组织损伤，对同源和异源毒株攻毒均未提供充分保护，整体保护效率有限。

这个“失败”结果教会我们什么？

① 安全 ≠ 有效：减毒株安全了，却未必能诱导足够强的保护性免疫；② 非洲猪瘟病毒免疫逃逸与保护机制非常复杂，单一缺失可能“剪过头”，把激发保护的抗原也削弱了；③ 疫苗研发是“安全—有效—稳定”三者的反复平衡，评价要靠严谨的攻毒保护试验。这正是科研规范与诚实报告的思政落点。

🚚 3.3 基因工程活载体疫苗的研制

课件逻辑：把“目的基因 B”装进“复制缺陷的病毒载体 ΔA”，让载体把基因送进细胞表达抗原。

准备①目的基因 B 制备编码保护性抗原的基因
+
准备②病毒 A 复制基因敲除得到复制缺陷载体 病毒ΔA
→
重组重组病毒（ΔA+B）获得把 B 装入 ΔA 载体
→
验证重组病毒 B 基因表达检测确认能正确表达目的抗原
→
生产制备疫苗规模化培养、纯化、灌装、质控
为什么载体要“复制缺陷”？

载体病毒自身复制基因被敲除（病毒 ΔA），所以它在体内不能有效增殖致病，只负责“送快递”——把外源抗原基因 B 送进宿主细胞，让细胞自己合成抗原蛋白，从而像“体内微工厂”一样同时激活体液与细胞免疫。

应用范例：重组新冠疫苗（5 型腺病毒载体）

课件：我国科研人员研发的重组新型冠状病毒疫苗（5 型腺病毒载体），以人复制缺陷型 5 型腺病毒为载体，插入新冠病毒刺突蛋白（S 蛋白）基因以诱导免疫应答，适用于预防新型冠状病毒感染引起的疾病，单剂接种后 14 天可形成保护。这正是“ΔA 载体 + 目的基因 B”策略在重大疫情中的一次成功落地。

🧩 3.4 难点突破：如何区分“疫苗株”和“野毒株”？

课件提问：弱毒疫苗无法区分疫苗株和自然感染野毒株，怎么办？如何区分疫苗和野毒株？

先理解问题有多严重

防疫部门要靠“血清学阳性率”判断猪群是否感染野毒。如果打的弱毒疫苗产生的抗体和野毒感染产生的抗体“长得一模一样”，那就分不清——明明只是打了疫苗，却可能被当成野毒阳性场，影响检疫、扑杀决策与净化认证。这就是活疫苗“免疫好却难收场”的根源。

方案 1：基因缺失标记疫苗

  • 疫苗株特意缺失某个野毒株都有的基因（如 gE、CD2v）
  • 检测“针对缺失基因的抗体”→ 阳性=感染过野毒，阴性=只打过疫苗
  • 一句话：给疫苗株“做个记号”，从而能区分疫苗和野毒株
+

方案 2：分子鉴别检测

  • 用 PCR / 测序直接检测病原核酸中的标记基因
  • 从临床样本（血液/组织）里查“有没有那个缺失片段”
  • 与血清学（查抗体）互补，实现“双保险”
别忘了缺点的另一面（课件）

基因缺失疫苗病毒可能会与野毒株重组或发生核酸修补，使缺失基因恢复而重获毒性——因此基因缺失苗的“标记”并非一劳永逸，仍需配合生物安全与分子监测。理解这一点，你就读懂了课件反复追问“怎么办/如何区分”背后的防疫智慧。

🧠 3.5 小结与自检

本模块知识地图

基因缺失疫苗：明确毒力基因 → 删除 → 减毒株 → 制备；兼具“减毒 + 可标记”。基因工程活载体疫苗：目的基因 B + 复制缺陷载体 ΔA → 重组病毒 → 表达检测 → 制备；让细胞“现产抗原”。两者都指向同一目标：安全地把有效抗原交给免疫系统，并尽量“留下身份记号”。

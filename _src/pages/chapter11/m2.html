Module 2 · 传统疫苗研制（一）

模块二：灭活疫苗与弱毒活疫苗的研制

传统疫苗分两大类：灭活疫苗（死疫苗）与弱毒活疫苗。它们都以“全病毒”为原料，但一条“杀之再用”、一条“弱而用之”，免疫效果与安全性正好相反——本模块用两条研制流程讲清这对“矛盾兄弟”。

研制流程优缺点对比应用范例（猪瘟C株）

🎯 学习目标卡

  • 能按顺序复述灭活疫苗的研制流程（选株→培养→灭活→制苗）
  • 能说出甲醛灭活疫苗的基本思路与“研制周期短、安全性高”的优点
  • 能复述弱毒活疫苗研制流程，并说出“人工致弱”与“自然筛选”两种来源
  • 能说明弱毒活疫苗为什么免疫原性更强（体内增殖模拟自然感染）

💀 2.1 灭活疫苗（死疫苗）的研制

课件思路：把“毒力强、免疫原性好”的毒株大量培养后彻底灭活，保留其免疫原性。

① 选株选择毒力强、免疫原性好毒株好“教具”才有好疫苗
→
② 扩增大量培养在适宜细胞/鸡胚/动物中增殖病毒
→
③ 灭活1% 左右甲醛灭活杀死病毒，使其失去感染性
→
④ 制苗保留免疫原性＋佐剂加佐剂增强免疫应答，配制成疫苗
为什么用“毒力强”的毒株来灭活？

毒力强往往意味着免疫原性好、抗原量足——既然目的是把它“杀死后当教具”，我们只需要它“样子像敌人”，不需要它活着。甲醛灭活（课件：1% 左右甲醛灭活）破坏病毒核酸/蛋白的感染性，却尽量保留能刺激免疫系统的抗原表位。灭活必须彻底，否则“死疫苗不死”会造成严重生物安全事故（模块四思政点会再讨论）。

优点 / 缺点说明（课件）
✅ 优点研制周期短、安全性高——病原已灭活，不会在体内增殖致病，免疫抑制动物也相对安全
⚠️ 缺点免疫原性较差（需多次接种、加佐剂）；成本较高、注射不便；通常主要诱导体液免疫，细胞免疫较弱
为什么灭活疫苗“免疫原性较差”？

因为病毒已被杀死、不能在体内增殖——抗原“一次性进场”，数量有限且刺激时间短；且灭活处理可能损伤部分构象表位。对策正是课件箭头里的两个词：加佐剂（增强免疫原性）＋ 多次免疫（加强免疫）。这就是为什么很多灭活疫苗说明书要求“首免—二免”并配合佐剂使用。

🦠 2.2 弱毒活疫苗的研制

课件：弱毒疫苗生产的核心是获得“大规模、高效、稳定”的弱毒株。

① 病毒选择与处理弱毒株来源自然界筛选弱毒株；或强毒株人工致弱
→
② 培养与扩增病毒培养与扩增大规模、高效、稳定——弱毒疫苗生产核心
→
③ 纯化与检测病毒纯化与检测无其他菌/毒检测、理化性质检查，去除杂质，保证质量与安全
→
④ 制备疫苗配方与配比、混合与均质化、佐剂混合灌装、质控、储存

🌿 自然筛选弱毒株

从自然界（动物群、环境中）寻找天然毒力已经很弱、但免疫原性保留的毒株。

或

🔬 强毒株人工致弱

让强毒株在非天然宿主/细胞/低温等条件下反复传代，迫使其毒力下降（经典的“异源宿主传代致弱”）。

为什么弱毒活疫苗“免疫效果更好”？（对应 2.1 的伏笔）

弱毒株接种后在体内仍能低水平增殖，像一场“极轻的感染”持续刺激免疫系统——抗原产量足、刺激时间长，能同时诱导体液免疫（抗体）＋细胞免疫（T 细胞），免疫原性通常强于灭活疫苗，因此常只需较小剂量、用量少、成本低、接种方便（课件“活疫苗优点”）。

🏆 2.3 应用范例：猪瘟弱毒疫苗 C 株

课件：猪瘟弱毒疫苗的研制与应用——中国赠送给匈牙利 C 株疫苗种毒。

中国疫苗走向世界的范例（课件内容）

猪瘟（Classical Swine Fever）是对养猪业危害极大的传染病。中国研制成功的猪瘟兔化弱毒疫苗（C 株）是世界公认的优秀弱毒疫苗，具有安全、稳定、免疫原性好、保护谱广等优点，为我国乃至世界猪瘟防控作出了重大贡献——课件特别提到，中国曾将 C 株疫苗种毒赠送给匈牙利，帮助其开展猪瘟防控。这是“中国制造”疫苗国际合作的一个缩影（思政页将进一步展开）。

联系生产实际

“C 株是弱毒活疫苗”——正因为它能在猪体内轻度增殖，才能用较小剂量诱导稳固的群体免疫，成为猪瘟疫苗的“金标准”。思考：为什么这样一种优秀的“活疫苗”，兽医们却一直惦记着“怎么分清疫苗毒和野毒”？——这正是下一模块与模块四的难点：鉴别疫苗株与野毒株。

🧠 2.4 小结与自检

两条路线一句话对照

灭活疫苗：毒力强株→大量培养→甲醛灭活→保留免疫原性+佐剂。安全、周期短，但免疫原性差、需多次接种。弱毒活疫苗：自然筛选/人工致弱→培养扩增→纯化检测→制苗。可在体内增殖、体液+细胞免疫兼得，用量少成本低，但需严防“疫苗株与野毒株分不清”。

模块自测M2 · Q2
弱毒活疫苗因能在体内低水平增殖、同时诱导体液免疫与细胞免疫，通常免疫原性优于灭活疫苗，且用量少、接种方便。

复习 2.2 弱毒活疫苗
启发性问题（带着它进入模块三）

活疫苗“免疫好”却“身份难辨”——弱毒疫苗无法区分疫苗株和自然感染野毒株。科学家用“基因手术刀”改造病毒来解决这个难题：删掉毒力基因、或把病毒做成“快递车”。这就是下一模块的基因缺失疫苗与基因工程活载体疫苗。

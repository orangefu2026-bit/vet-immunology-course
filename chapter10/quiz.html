选 D。抗原—抗体结合靠氢键、静电、范德华力等非共价可逆作用；特异性、可逆性、比例性、阶段性才是其特点。

判断2 / 14 · 模块一
课件认为检测是动物疫病防控和净化的核心；中国畜禽诊断市场前景广阔，国家政策高度支持新型诊断方法开发。
正确。两句均为课件表述（检测意义页）：检测是防控与净化的核心，行业青睐精准现场快速便捷的方法，市场前景广阔且获政策支持。
对应：模块一 1.1–1.2 → 去复习
单选3 / 14 · 模块一
在抗原—抗体体外反应中，当抗体过量时反而可能不出现肉眼可见的凝集 / 沉淀（前带现象），这体现了抗原—抗体反应的：
选 C。反应需抗原抗体比例适当才形成最大可见产物；一方过量（前带 / 后带）会抑制可见反应。这也提示：样品过浓时宜稀释后检测。
对应：模块一 1.3 → 去复习
单选4 / 14 · 模块二
用布病虎红平板凝集试验筛查布鲁氏菌病（以菌体悬液为抗原、与血清抗体直接凝集），该方法属于：
选 A。颗粒性抗原（细菌）直接与相应抗体结合形成凝集 = 直接凝集；间接凝集是把可溶性抗原先吸附到乳胶 / 红细胞等载体上再做。
对应：模块二 2.2 → 去复习
单选5 / 14 · 模块二
用间接 ELISA 检测某猪群抗体时，使“待检抗体”能被显色“看见”的关键元件是：
选 B。间接 ELISA 用“酶标二抗”识别并结合待检抗体（一抗）的恒定区，把“动物有没有针对某抗原的抗体”转译成底物显色。包被抗原负责捕获，二抗负责报告。
对应：模块二 2.4 → 去复习
多选6 / 14 · 模块二
下列属于免疫标记技术（借助标记物产生信号）的有：
选 A、B、C、D。它们分别以酶、荧光素、胶体金、化学发光物为标记物；环状沉淀试验依靠自身形成沉淀环、不用标记物，属经典沉淀反应。
对应：模块二 2.1–2.3 → 去复习
单选7 / 14 · 模块二
为什么 ELISA 能检测出极微量的病毒抗原？最核心的原因是：
选 B。ELISA 靠“特异性结合（认得）+ 酶催化底物放大信号（看得见）”：一个酶分子可催化大量底物分子显色，把不可见的分子结合变成可定量读数。
对应：模块二 2.4 → 去复习
单选8 / 14 · 模块三
关于胶体金，正确的描述是：
选 A（课件定义原文）。胶体金呈不同程度的红色悬浮液；在弱碱环境下带负电的胶体金可与蛋白质等正电荷基团牢固结合，用于标记抗体 / 抗原。
对应：模块三 3.1–3.2 → 去复习
判断9 / 14 · 模块三
抗原检测试纸条判读：阳性样品的检测线（T 线）与质控线（C 线）同时显色，阴性样品只有质控线显色。
正确。这是课件“结果判定”原文：阳性 T+C 同时显色，阴性仅 C 显色；C 线不显色则试纸条无效。
对应：模块三 3.4 → 去复习
单选10 / 14 · 模块三
抗体检测试纸条（如新冠 IgG 抗体检测）中，结合垫内被胶体金标记的是：
选 A。测抗体时金标的是“病原重组抗原”（带信号旗的抗原）；样品抗体先抓住金标抗原，复合物再到 T 线被固定的“抗人 IgG 等抗抗体”拦截显色。
对应：模块三 3.3 → 去复习
判断11 / 14 · 模块三
质控线能显色的原因在于：C 线固定的山羊抗鼠 IgG 通过识别鼠源 IgG 恒定区（CH1–CL，同种异型区域）拦截流经的金标鼠源抗体，与其针对哪个表位无关。
正确。这正是课件“常见问题”的答案：抗体的同种异型区域（鼠源 IgG 的 CH1–CL 基本相同）决定了山羊抗鼠二抗能结合任何鼠源金标抗体。
对应：模块三 3.4 → 去复习
单选12 / 14 · 模块四
某试纸条能把已知阳性样品正确检出的比例越高，说明该方法：
选 A。敏感性 = 真阳性检出能力（“有敌情能不能发现”），敏感性的反面就是漏检（假阴性）；特异性管的是阴性样品会不会被误报。
对应：模块四 4.3 → 去复习
单选13 / 14 · 模块四
现场检测把阴性样品误报为阳性（假阳性）的常见原因是：
选 B。交叉反应与抗原不纯引起的非特异性结合是把阴性报成阳性的常见原因（降低特异性）；A、C 主要导致假阴性（漏检），D 也会致漏检。
对应：模块四 4.3 → 去复习
情境 · 不计分14 / 14 · 迁移应用
某猪场用一款“PEDV 抗原快速检测试纸条”对腹泻病料进行初筛，检出若干“弱阳性”。场长据此要求马上淘汰相关母猪，但一名员工提出异议：会不会是试纸条误报？请你以兽医免疫学顾问的身份，写出你的处置建议（提示：可从 C 线质控、弱阳性处理、快检与确诊分工、灵敏性 / 特异性 / 假阳假阴、生物安全等角度展开）。
参考思路（开放题，言之成理即可）：① 先核质控：C 线是否正常显色，C 缺失则该批结果无效，不可作为决策依据；② 弱阳性按说明书规定时间判读，T 线颜色极浅时建议同盒复测或双人复核，排除判读超时等操作误差；③ 明确快检定位：试纸条是初筛，淘汰属于重大决策，应把可疑样品与同群样品送实验室用确诊方法（分子 / 权威试剂）复核，避免“错检误杀”；④ 方法学层面：任何检测都有假阳（交叉反应）与假阴（窗口期 / 灵敏度不足），应结合流行病学（发病率、临床症状）综合判断；⑤ 处置须符合生物安全与上报规范，阳性样品与纸条废弃物按规定处置——专业 + 规范，才是对养殖户与公共安全负责。
综合：模块三 结果判定 + 模块四 质控与假阳假阴 + 案例一/三

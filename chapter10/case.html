案例教学：把“检测”用起来

三个案例分别对应“猪场一线快检 → 试剂盒研发（实验室成果）→ 净化决策”三个兽医场景。学习方式：先读背景，暂停播放，自己写答案，再展开解析。案例解析按“背景 → 问题 → 知识分析 → 教师总结 → 专业启示”展开。

教学情境 + 课件成果理论→分析→判断→应用建议小组讨论

🐷 案例一：猪舍里的“十分钟侦察”——腹泻病料现场快检

教学情境 · 猪场一线思政：不能慢检、不能漏检、不能错检

① 案例背景（课堂教学情境）

某规模化猪场（教学情境）产房仔猪突发急性水样腹泻、死亡率攀升，场长怀疑与猪流行性腹泻病毒（PEDV）有关。当日刚好有业务员上门推销“PEDV 抗原快速检测试纸条”，号称“十分钟出结果、当场就能定要不要隔离淘汰”。场长向你（驻场兽医 / 动物医学实习生）求助：这张试纸条能信吗？现场该怎么用？

② 临床 / 生产问题

  • 现场判断“是不是 PEDV”，试纸条检测的是抗原还是抗体？为什么这个时机该测抗原？
  • 试纸条出现“T、C 两条线”一定可靠吗？出现“只有 C 线”能排除 PEDV 吗？
  • 现场快检与“送实验室确诊”是什么关系？什么情况下必须送检复核？

③ 知识分析（免疫检测视角）

处置 / 现象免疫学角色对应本章知识
暴发早期取病料测“抗原”抗原检测回答“病原现在在不在”（现症感染）抗原检测模式（M3）
T + C 同时显色判阳性特异性结合（认得）+ 金标信号（看得见）结果判定（M3）
C 线不显色判无效、复测质控线 = 试剂自检，防止假阴性质量控制（M3/M4）
初筛阳性 → 送实验室确诊快检作初筛，权威方法作确诊，避免假阳假阴误决策方法学评价、三类检测目标（M4）
④ 教师总结

现场快检的价值在于“十分钟拿到一个方向的判断”，而不是“一张纸条终结诊断”。读结果一定要按规矩来：先看 C 线（纸条有没有坏），再看 T 线（有没有目标物）；弱阳性、可疑结果必须复测或送实验室复核。快检负责“快与广”，实验室负责“准与定性”——这才是“不能慢检、不能漏检、不能错检”的正解。

⑤ 专业启示 · 课程思政

一张试纸条背后是“早发现、早处置、防扩散”的防疫逻辑：快检越普及，疫情越可能在“一个场”的范围内被摁住，而不是蔓延成“一片”。基层兽医掌握判读规范，就是守住生物安全与养殖户利益的第一道防线。

🗂 本案例考查的知识点清单
  • 抗原检测 vs 抗体检测的选择（M3/M4）
  • T 线 / C 线判读与无效处理（M3）
  • 质控线防假阴性的意义（M3/M4）
  • 初筛与确诊的分工（M4）

🥛 案例二：给“母乳里的抗体”做一张试纸条（课件实验室成果）

科研 · 课件实验室成果思政：自主诊断产品研发

① 案例背景

仔猪出生后靠母乳获得被动免疫，乳汁中的分泌型 IgA（sIgA）是评估母源免疫状态的关键指标。课程团队研发了两款检测母乳中 PEDV sIgA 抗体的免疫层析试纸条（分别以荧光微球、量子点为标记物，课件“实验室成果”），并在 100 份临床母乳样品上与商品化试剂盒比对：两款自研试纸条阳性检出率均约 95%，与商品化试剂盒符合率分别约 92.63%（荧光微球）与 95.79%（量子点）。

② 科研 / 生产问题

  • 为什么测“抗体（sIgA）”而不是“抗原”？研发要先解决“测什么、拿什么当金标物”？
  • 为什么做了 4 类评价：特异性、敏感性、重复性，还要与商品化试剂盒算“符合率”？
  • 从胶体金到荧光微球 / 量子点，换标记物解决了什么问题？（提示：灵敏度与读卡）

③ 知识分析

研发环节 / 现象（课件）免疫学角色对应本章知识
测母乳 sIgA 抗体评估母猪免疫应答 / 母源保护，用“抗体检测”逻辑抗体检测试纸条设计（M3）
金标物 = 重组抗原 + 荧光微球 / 量子点重组抗原作识别元件，荧光 / 量子点作更灵敏的信号旗标记物家族、研发路线（M2/M4）
特异性、敏感性、重复性评价证明测得准、不误报、批间稳定方法学评价（M4）
与商品化试剂盒比对（符合率 ≥92%）以“成熟方法”为参照验证新方法可用符合率（M4）
④ 教师总结

这个案例把本章的“研发—评价—应用”链条走了一遍：先定检测目标（sIgA 抗体）→ 造识别元件（重组抗原）→ 选信号旗（荧光微球 / 量子点）→ 系统评价（特异 / 敏感 / 重复 / 符合率）→ 推向一线。数据告诉我们：自研可视化试纸条能达到与商品化试剂盒相当甚至更高的符合率——说明“国产替代、自主诊断”在技术上完全走得通。

⑤ 专业启示 · 课程思政

把“实验室里的抗体检测”做成“猪舍里能用的试纸条”，就是科技成果转化。我国畜禽诊断市场前景广阔（课件），谁掌握核心原料（重组抗原、标记物）与评价标准，谁就掌握动物疫病监测的主动权——这正是“把论文写在祖国大地上”的兽医版本。

🗂 本案例考查的知识点清单
  • 抗原检测 vs 抗体检测（M3）
  • 重组抗原与标记物偶联（M2/M4）
  • 敏感性 / 特异性 / 重复性 / 符合率（M4）
  • 诊断产品研发与应用转化（M4）

🧯 案例三：无疫苗无药，拿什么“断舍离”——重大疫病的净化决策

教学情境 · 净化与扑杀思政：依法防控、稳产保供

① 案例背景（课堂教学情境）

非洲猪瘟等重大疫病无商品化疫苗、无可用药物（课件），防控几乎完全依赖“检测 — 淘汰 — 扑杀”。某猪场相邻地区出现疑似疫情（教学情境），上级要求该场开展排查。现场只有快速筛查手段，场里人心惶惶：有人主张“宁杀勿漏”，有人担心“误杀无辜”——检测结果到底能不能作为淘汰依据？

② 临床 / 生产问题

  • 排查阶段用“抗原快检”还是“抗体检测”？为什么早期排查主要看抗原？
  • 若筛查出阳性，直接扑杀前还缺哪一步？为什么“错检”和“漏检”都不可接受？
  • “宁杀勿漏”与“误杀无辜”之间，免疫学检测能提供什么客观支撑？

③ 知识分析

决策环节免疫学角色对应本章知识
早期排查测抗原现症感染（带毒排毒）阶段抗原阳性率高抗原检测原理（M3）
快检阳性 ≠ 直接扑杀快检可能有假阳假阴，须复核确诊假阳假阴与质控（M4）
实验室确诊作为扑杀依据以更高特异性的确诊方法支撑行政决策，避免“错检”初筛 / 确诊分工（M4）
多轮检测 — 淘汰 — 扑杀窗口期与误差要求反复筛查，直到群体阴性稳定监测应用（M4）
④ 教师总结

扑杀决策是“最重的一刀”，必须由最可信的证据支撑。快检解决“快”与“广”，确诊解决“准”；质控线、阴阳性对照、复核送检这些看似繁琐的细节，恰恰是“不错杀一头、也不放过一头”的免疫学保障。对检测结果心存敬畏、按流程走，才是对养殖户和公共安全最大的负责。

⑤ 专业启示 · 课程思政

重大疫病防控关乎生猪稳产保供与公共安全，我国坚持依法防控、科学防控：检测—报告—处置各环节都有规范流程。兽医在其中的角色，是用扎实的检测知识与规范操作，把“科学”二字写进每一次扑杀与每一张放行单里。

🗂 本案例考查的知识点清单
  • 抗原 / 抗体检测的目的差异（M4）
  • 假阳 / 假阴与质量控制（M4）
  • 初筛与确诊分工（M3/M4）
  • 检测在疫病净化中的应用（M4）
案例教学小结（对照“理论→分析→判断→应用”）

三个案例的共同“公式”：识别威胁（怀疑什么病）→ 选对目标（测抗原还是抗体）→ 读懂信号（T 线 C 线怎么判）→ 守住底线（质控与复核）→ 落到决策（处置、研发、净化）。你可以在课后作业“提升层”里再独立走一遍这个公式。

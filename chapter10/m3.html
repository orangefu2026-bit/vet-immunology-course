Module 3 · 让敌情“现形”的试纸条

模块三：可视化快检——胶体金免疫层析试纸条

一张几块钱的试纸条，为什么能在一线战场（猪舍、禽舍、出诊箱）让看不见的病毒“现出原形”？本模块按课件把胶体金试纸条的概念、抗原检测原理、抗体检测原理、结果判定与常见问题讲透——这是本章的“主战役”。

课件核心原理 + 判读难点突破

  • 能复述胶体金与胶体金试纸条的定义（课件原文）并画出试纸条的基本结构

📖 3.1 概念：胶体金与胶体金试纸条

课件原文定义，先记“金”再记“纸条”。

胶体金（Colloidal Gold）

由氯金酸在还原剂作用下，聚合成为特定大小的金颗粒，并由于静电作用成为一种稳定的胶体状态，称为胶体金。

胶体金试纸条（免疫层析试纸条）

以胶体金作为示踪标记物，以硝酸纤维素膜（NC 膜）为载体，利用微孔膜毛细管作用，基于抗原—抗体反应的一种新型免疫标记快检技术。

两个“直观”：① 金颗粒有颜色——不同粒径的胶体金呈不同程度红色（课件图示），肉眼可直接看到；② 纸会“虹吸”——液体借 NC 膜毛细管作用自行向前流动，无需外加动力和仪器。把这两点结合，就得到“现场可视化”的快检。

图 3-1 试纸条“一条纸上的层析铁路”：样品垫滴样 → 结合垫释放金标识别元件 → NC 膜上发生特异性结合并被 T 线拦截显色 → 多余金标被 C 线拦截显色 → 吸水垫引流。

🦠 3.2 抗原检测原理：让“病毒抗原”现形

以课件“新冠病毒抗原检测试纸条”为例，逐步拆解（原理同样适用于动物疫病抗原快检）。

第 1 步：制备金标抗体

胶体金颗粒带负电荷，在弱碱环境下，会与蛋白质等正电荷基团形成牢固结合。利用这一作用，让抗体吸附于胶体金颗粒表面，制成金标抗体；同时把特异性抗体以条带状固定在膜上（T 线），并把另一种抗体固定在 C 线位置。

第 2 步：加样，特异性结合 + 侧向流动

滴加待检样品后，结合垫中的金标抗体与样品中的待检抗原结合，形成抗原—金标抗体复合物，并随液体开始侧向流动。以新冠抗原检测为例：样品中若含有新冠病毒 N 蛋白（抗原），会与金标鼠源抗 N 蛋白单克隆抗体（抗体 A）结合。

第 3 步：T 线拦截显色，C 线质控显色

膜上位置固定的是什么拦截谁 → 结果
检测线 T抗 N 蛋白多克隆抗体 B拦截“抗原—金标抗体复合物”→ 复合物聚集显色（阳性信号）
质控线 C山羊抗鼠特异性 IgG 抗体 C（识别鼠源 IgG）拦截未被 T 线拦截的金标鼠源抗体（及部分复合物）→ 聚集显色（纸条有效信号）
图 3-2 抗原检测试纸条的三种判读结局（虚线框 = 该线不显色）。C 线恒定显色是“试剂有效”的通行证；C 线不显色一律按无效处理，防止假阴性。

💉 3.3 抗体检测原理：让“抗体”现形

难点突破：测抗体时，角色发生了“大对调”——金标的是抗原，T 线固定的是“抗抗体的抗体”。

先想 10 秒：为什么测抗体不能用“测抗原”那套搭配？

测抗原时我们靠“抗病原抗体”去捕获病原；可要测的如果是“动物自己产生的抗体”，就必须先有一个能把它“钓住”的东西——动物抗体的身份特征是它的恒定区（种属特性），所以要用“抗这种抗体的抗体”（如抗人 IgG）去钓它。

部件（以新冠 IgG 抗体检测为例，课件）是什么 / 干什么
结合垫中的金标物胶体金标记的鼠源重组 N 蛋白（重组抗原）——不是金标抗体，而是“带信号旗的抗原”
样品中待检物可能含有抗 N 蛋白的 IgG 抗体（人 / 动物感染或免疫后产生）
检测线 T固定抗人 IgG 抗体 B（识别 IgG 恒定区）→ 拦截“样品抗体—金标重组抗原”复合物并显色
质控线 C固定抗 N 蛋白抗体 C → 拦截未被结合的游离金标重组抗原并显色

逻辑链：样品中的抗 N IgG 先“抓住”金标重组抗原 → 这个复合物流到 T 线，又被固定的抗人 IgG 抓第二下（夹心）→ T 线显色 = 样品里有针对 N 蛋白的 IgG。游离的金标重组抗原则一路流到 C 线，被抗 N 蛋白抗体拦截显色 = 纸条工作正常。

测抗原 vs 测抗体——一张表分清“谁被金标、T 线固定什么”

抗原检测试纸条：金标 = 抗病原抗体（金标抗体）；T 线 = 抗病原抗体（第二只“手”）；C 线 = 抗鼠（等种属）IgG 二抗。
抗体检测试纸条：金标 = 病原重组抗原；T 线 = 抗动物抗体恒定区的抗体（抗人 IgG / 抗猪 IgG 等）；C 线 = 抗该病原抗原的抗体。

共同点：T 线回答“有没有目标物”，C 线回答“纸条有没有坏”。

✅ 3.4 结果判定与常见问题（难点突破）

课件“结果判定 + 为什么金标抗体能和质控线抗体结合”。

判读T 线（检测线）C 线（质控线）结论
阳性显色显色检出目标物，报告阳性（抗原检测时 T+C 同时显色）
阴性不显色显色未检出目标物，报告阴性（只有质控线显色）
无效—不显色纸条失效（无论 T 线是否显色均不采信），需换新条重测
课件常见问题：为什么金标抗体可以和质控线抗体相互结合？

因为质控线固定的“山羊抗鼠 IgG”识别的，是抗体的遗传标志区域（同种异型差异区域）。例如：金标抗体是鼠源 IgG（一抗），鼠源 IgG 的 CH1–CL 区基本相同；而“山羊抗鼠二抗”是用纯化的小鼠 IgG 免疫山羊获得的血清，因此能识别并结合任何鼠源 IgG——不管它针对的是哪个病毒的哪个表位。

为什么 C 线“与测什么无关却必须显色”？

  • 金标识别元件（无论是否结合了目标物）都会流经 C 线并被拦截 → 只要有足量金标抗体、层析正常，C 线就应显色
  • C 线不显色 = 金标缺失 / 层析受阻 / 试剂失效 → 结果不可信
↔

这就是“防假阴性”的质控设计

  • 没有 C 线时，若纸条失效，样品阴性会被“照单全收”，造成漏检
  • C 线把“纸条自身的失败”与“样品真的阴性”区分开，呼应课件“不能漏检、不能错检”
判读小提醒

① T 线颜色深浅通常与目标物含量相关，但现场判读以“有 / 无”为准，精确含量请送实验室定量；② 必须在说明书规定时间内判读，放置过久可能产生假阳性线条；③ 阳性样品处理与纸条废弃物处置要遵守生物安全规范（衔接课程思政）。

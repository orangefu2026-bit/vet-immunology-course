Module 3 · 功能谱与难点突破

模块三：细胞因子功能谱与“双刃剑”

本模块回答本章主线问题：细胞因子什么时候“有利”、什么时候“有害”？先看“正常剧本”——细胞因子怎样指挥 Th1/Th2/Th17/调节性 T 细胞分工；再看“失控剧本”——促炎网络为何会演变成细胞因子风暴。这是本章的教学难点，请结合图示慢慢读。

本章重点本章难点含可视化课件功能句集中页

🎯 学习目标卡

  • 能说清 Th1、Th2、Th17、调节性 T 细胞的诱导分化因子与效应因子及功能偏向
  • 能按“抗病毒 / 炎症 / 造血 / 免疫调节”四类功能举例对应细胞因子
  • 能用自己的话解释“促炎—抗炎”“Th1—Th2”平衡失衡如何致病
  • 能复述细胞因子风暴的定义（课件），并说明其与 ARDS、多器官衰竭的关系及治疗方向

🧬 3.1 临床意义的“四个舞台”（课件）

课件指出：细胞因子具有调节免疫应答、刺激造血功能、促进创伤的修复和调节神经-内分泌-免疫网络的临床作用。

临床作用代表细胞因子通俗解释
调节免疫应答IL-2、IL-12、IFN-γ、IL-10、TGF-β 等决定免疫细胞发育/分化/功能，抗感染、抗肿瘤等（课件）；正负信号都有
刺激造血功能CSF、EPO 等维持血细胞生成，临床可用于贫血等（课件）
促进创伤的修复EGF、FGF、PDGF、VEGF 等生长因子促进上皮、肉芽、血管生成与组织愈合（课件）
调节神经-内分泌-免疫网络IL-1、IL-6 等免疫系统与神经、内分泌系统“通话”：如促炎因子作用于中枢引起发热、食欲下降（公共知识）

🧭 3.2 CD4⁺T 细胞的分化与细胞因子谱（重点）

初始 CD4⁺ T 细胞“听到”不同细胞因子信号后分化成不同亚群——就像同一批新兵被不同号令训练成不同兵种。课件功能句是这张表的“出厂说明书”。

以课件功能句为纲（诱导因子/效应因子均按课件与教材公共知识标注）
亚群诱导分化的细胞因子（课件）主要分泌的效应细胞因子功能偏向 / 免疫学角色（课件功能句）病理关联
Th1IL-12、IFN-γ 促进 Th1 分化IFN-γ、TNF 等细胞免疫：IFN-γ 激活 Mφ 杀灭病原微生物；IFN-γ、IL-2 活化 NK、CTL 杀伤靶细胞抗胞内菌/病毒；过度→炎症损伤
Th2IL-4 等诱导（教材公共）IL-4、IL-5、IL-13 等体液免疫：IL-4、IL-6 促 B 细胞活化和增殖；参与抗体产生与抗蠕虫免疫IL-4、IL-5、IL-6、IL-13 促 IgE → 过敏/超敏（课件）

推理题（检验是否真懂）

某胞内病原（如结核分枝杆菌、胞内寄生菌）感染时，机体最该优先调动哪一类 CD4⁺ T 细胞应答？为什么“只靠抗体”往往不够？

参考思路（先自己推理再看）

应优先 Th1：IFN-γ 激活 Mφ 杀灭被吞入的胞内病原，IFN-γ/IL-2 再激活 NK、CTL 清除藏匿的病原（课件功能句）。抗体主要在细胞外起作用，对已躲进细胞内的病原“够不着”，所以必须靠细胞免疫。这也是疫苗评价常测 IFN-γ/CTL 的原因。

🗺️ 3.3 “功能—分子”对照速查表

从临床问题倒过来查：要抗病毒、要促炎、要造血、要刹车，分别找谁？

需要实现的效应主打细胞因子补充说明
广谱抗病毒I 型干扰素：IFN-α、IFN-β诱导邻近细胞“抗病毒状态”（模块二）
激活巨噬细胞抗病原IFN-γ（II 型干扰素）课件：IFN-γ→Mφ 杀灭病原微生物
杀伤靶细胞 / 诱导凋亡IFN-γ、IL-2、TNF-α、FasL课件：作用于 NK、CTL，杀病毒/肿瘤靶细胞
促炎 / 致热（适度时抗感染）IL-1、IL-6、TNF-α“促炎三巨头”，也是风暴主角（3.4）
刺激造血CSF 家族、EPO治疗肾性/癌症贫血（课件）
抑制免疫 / 抗炎（刹车）IL-10、TGF-β课件：二者抑制免疫系统功能；TGF-β 还诱导 Treg
促进组织修复 / 血管生成EGF、FGF、PDGF、VEGF 等创面愈合制剂（课件，模块四）

⚠️ 3.4 难点突破：双刃剑与“细胞因子风暴”

课件点题：细胞因子的多效性、网络性等特点使其在疾病发生中也发挥不利的调控作用——抑制或中和细胞因子成为疾病治疗的方向。

细胞因子风暴的定义（课件原文）

细胞因子风暴是引起急性呼吸窘迫综合征（ARDS）和多器官衰竭的重要原因。

为什么正常防御会“翻车”？——把网络性×级联放大看成一个回路，当“刹车”失灵：

图 3-1 细胞因子风暴的发生逻辑：病原大量入侵 → 促炎因子（IL-1、IL-6、TNF-α 等）级联放大 → 全身性血管与组织损伤 → 急性呼吸窘迫综合征（ARDS）、多器官衰竭（依据课件“细胞因子风暴”句与教材公共知识绘制）。因此临床上把“抑制或中和细胞因子”作为治疗方向（课件）。

第二张“有害的脸”：免疫性疾病与超敏

  • Th2 型因子过量是过敏/超敏的推手：课件指出 IL-4、IL-5、IL-6 和 IL-13 等细胞因子可促进 IgE 生成及增强活性，从而参与 I 型超敏反应（衔接第九章“超敏反应”）；
  • 促炎—抗炎失衡还参与许多自身免疫性/炎症性疾病——理解“刹车失灵”，就理解了这类疾病的细胞因子学基础。
一句话总结“何时有利、何时有害”

细胞因子本无“善恶”，关键在于量、靶、时机与网络语境：适度=抗感染/抗肿瘤/促修复（利）；过量/失衡/错位=风暴、过敏、免疫损伤（害）。所以兽医既可以把细胞因子“补”进去（模块四的干扰素/IL-2 产品），也可以“堵”它的通路（抑制剂类药物）——一补一堵，都是细胞因子的学问。

🧠 3.5 小结与自检

本模块知识地图

四个临床舞台（调节免疫 / 造血 / 修复 / 神经-内分泌-免疫网络）→ CD4⁺T 谱系（Th1 猛攻、Th2 抗体、Th17 增援、Treg 刹车）→ 功能-分子速查（抗病毒找 IFN、促炎找 IL-1/6/TNF、刹车找 IL-10/TGF-β…）→ 双刃剑（风暴=网络失控→ARDS/多器官衰竭；超敏=Th2/IgE 过量；治疗=抑制或中和）。回到主线问题：细胞因子“何时有利、何时有害”？——请用“量、靶、网络语境”六字回答。
